高性能模式（Moonlight / Sunshine）· 第三方组件说明
==================================================

本产品安装包里可以包含「高性能模式」组件：它以**独立程序**的方式安装开源软件
Sunshine（https://github.com/LizardByte/Sunshine），用于给手机上的 Moonlight 客户端
提供低延迟串流通道。网页模式不依赖它，卸载它也不影响网页模式。

组件信息
--------
名称      ：Sunshine（自建 GameStream 兼容串流服务端）
版本      ：2026.914.233613（打包时锁定；安装包文件名 Sunshine-Windows-AMD64-installer.msi）
许可证    ：GNU General Public License v3.0（GPL-3.0）
上游项目  ：https://github.com/LizardByte/Sunshine
上游发布  ：https://github.com/LizardByte/Sunshine/releases
我们做了什么：**只是安装它、写配置文件（绑定地址/端口/编码器策略/Web 凭据）、
           用它的官方 REST API 完成手机配对、并在卸载时清理配置**。
           我们没有修改 Sunshine 的源代码，也没有把它和本产品链接成一个程序。

客户须知
--------
- 高性能模式需要手机安装 Moonlight（第三方开源客户端）：Android 见
  https://github.com/moonlight-stream/moonlight-android/releases ；iOS 见 App Store。
- 高性能模式对所有用户开放（2026-11-08：产品完全免费，7 天试用规则已删除）（与产品的许可证规则一致）。
- 不想用可以直接卸载（安装目录里的 2-停止并清理.cmd -UninstallSunshine），不影响网页模式。
