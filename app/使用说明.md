### 关于两个入口（重要）

「手机入口」会给你**两个地址**：

| | 长什么样 | 用来干什么 |
|---|---|---|
| **主入口** | `https://xxx.ts.net/?k=...` | **平时用这个**。加密传输，还能"添加到手机桌面"变成 App |
| **备用入口** | `http://100.x.x.x:8660/?k=...` | **主入口打不开时用这个**。数字地址不依赖域名解析，一定能连 |

**两个都要存到手机书签里。** 主入口偶尔会因为这个那个打不开，备用入口通常还能进。

## 二、装到手机桌面（用起来像 App）

用**主入口**那个 https 地址打开，然后：

**安卓**：浏览器右上角 **⋮** → **「安装应用」**（或「添加到主屏幕」）

**iPhone**：用 **Safari** 打开 → 底部**分享** → **「添加到主屏幕」**
（不能用微信内置浏览器，那里没有这个选项）

装好后桌面上有个图标，**点开没有地址栏，全屏显示**，跟 App 一样。

> 如果你看到的是 `100.x.x.x` 这种数字地址，那个装不成 App——要装 App 必须用 https 的那个。
>
> **没有 https 地址？** 说明这个 Tailscale 账号还没开 HTTPS（一次性设置）：
> 1. 电脑上打开 <https://login.tailscale.com/admin/dns>
> 2. 找到 **HTTPS Certificates** → 点 **Enable HTTPS**
> 3. 回到电脑，双击「启动」（或等 1 分钟，守护进程会自动重配）
> 4. 重新打开「手机入口」，就会多出 `https://<机器名>.ts.net/` 这个能装 App 的地址
>
> HTTPS 只是让手机能"安装到桌面"；不开也能用 http 看画面，只是不能装成 App。

## 三、界面上每个按钮干什么

打开后顶上有一排按钮：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **清晰** | 高清画面，但占带宽 | 网速好、需要看清字 |
| **流畅** | 改用 WebRTC 传输（省 20 倍流量，24 帧；连不上会自动切回清晰） | 用手机流量时点这个 |
| **全部屏幕** | 选择抓哪块屏 / 哪个窗口 | 多显示器，或只想看某一个软件 |
| **桌面** | 一键最小化所有窗口 | 想快速找到桌面上的东西 |
| **声音** | 开/关电脑声音转发 | 需要听声音时 |
| **控制** | **总开关**。关掉后只能看，点不动 | 只想看不小心点错时，先关掉它 |
| **输入** | 打开打字面板 | 需要输入文字时（见下面第四节） |
| **省流量** | 降到 5 帧/秒、低分辨率 | 只想瞄一眼进度、或者流量很紧 |
| **命令** | 在电脑上执行 PowerShell 命令 | 高级功能，不懂别碰 |
| **设置**（右下角 ⚙） | 画质档位、个性化、许可证、版本信息 | 见下面「画质三档」和第八节 |
| **支持 / 购买**（右下角 ❤） | 机器码、收款码、卖家联系方式 | 买许可证、找人帮忙时 |

### 设置里的画质三档（右下角 ⚙）

| 档位 | 画面宽度 | 流量（清晰模式约） | 谁能用 |
|---|---|---|---|
| **超清** | 2560 | 约 26 GB/时 | 每人**每天免费 1 小时**；装了许可证**不限时长** |
| **高清** | 1920 | 约 15 GB/时 | 免费，不限时 |
| **标准** | 1440 | 约 8 GB/时 | 免费，不限时 |

- 超清的免费 1 小时**每天 0 点恢复**；用完后画面自动按高清出图，其他一切照常。
- 页面状态栏会显示今天超清还剩多少（比如「超清余 59 分钟」）。
- **切档位立即生效，不用重启。** 抓屏始终按电脑原分辨率进行，档位只决定"发到手机上的宽度"，
  所以三档的**帧率一样**，缩小用的是高质量算法，不会像以前那样越缩越糊。
- **手机上三档看起来差不多？正常。** 手机屏会把三档画面都压到屏幕宽度，正常距离看几乎一样。
  差别主要在 ① **文字密集的界面**（代码、表格、小字号软件）：超清的文字边缘更清楚，标准会糊一点；
  ② **流量**：超清约是标准的 3 倍。
  所以：文字多的工作选超清，日常用高清，流量紧选标准。
- **双指手势是滚轮，不是网页缩放**；两指一落下，光标会自动跑到两指正中并**固定在那里**，直到双指全部抬起。
- **三指及以上捏合/张开 = 缩放**：以所有手指的中心（手心）为缩放中心，等价于电脑上的 `Ctrl+滚轮`。
  在浏览器、资源管理器、Office 等支持该快捷键的窗口里有效，不是放大手机网页本身。
  想看更细：选超清档；或者用手机系统的放大功能（iPhone：辅助功能 → 缩放；安卓：无障碍 → 放大手势）。

## 四、⚠️ 用手机流量看之前，务必先看这一节

**这不是提示，是会花钱的事。** 下面每个数字都是实测值，不是估算。

### 三种模式的实际流量

| 模式 | 每小时流量 | 帧率 | 什么时候用 |
|---|---|---|---|
| **清晰** | **约 26 GB** | 24 | 只在**手机和电脑连同一个 WiFi** 时用 |
| **流畅** | **约 1.3 GB** | 24 | **用手机流量时点这个** |
| **省流量** | 约 1.1 GB | 5 | 只想瞄一眼、或者流量特别紧 |

### 为什么清晰的流量这么大

清晰模式是**每秒发 24 张完整的截图**，每张约 320 KB：

```
320 KB/张 × 24 张/秒 ≈ 7.5 MB/秒 ≈ 26 GB/小时
```

**30 GB 的月套餐，用清晰模式看一小时就没了。**

### 用流量时该点哪个

**点「流畅」。** 它省 20 倍流量，而且**帧率一样是 24 帧**（画面是顺的）。

省流量虽然更省一点点（1.1 vs 1.3 GB），但只有 5 帧/秒，操作会明显发飘——**除非你只是扫一眼有没有人在用，否则别选它。**

### 一句话记住

> **在家用 WiFi → 清晰。**
> **出门用流量 → 流畅。**
> **只想看一眼 → 省流量。**

### 如果点了「流畅」没画面

大概 5 秒后它会**自动切回清晰**，并在屏幕上提示你。这是正常的兜底，不是故障。

## 五、输入文字（这里最容易卡住）

### 方式一：文字面板（最稳，推荐）

1. 点顶上的 **「输入」**
2. 在面板里打字（支持中文、表情）
3. 点 **「发送」**

文字会一次性打进电脑上**当前光标所在的位置**。

⚠️ **发出去之后收不回来。** 就像有人在电脑前把这段话打进去了一样——打错了只能在电脑那边删。

### 方式二：特殊键按钮

「输入」面板下面有一排键：

```
退格  删除  回车  Esc  Tab
 ←     ↑     ↓     →
     撤销(Ctrl+Z)
```

- **退格 / 删除**：删字，不用回电脑前
- **回车**：确认、换行、发消息
- **方向键**：移动光标
- **撤销(Ctrl+Z)**：**只对支持撤销的软件有效**（记事本、Word、浏览器），很多软件里没用

### 方式三：接蓝牙键盘（装了 App 才有）

打开 App 后接蓝牙键盘，**打字会实时出现在电脑上**，跟坐在电脑前一样。

> 注意：光标在手机上的输入框里时，按键不会传给电脑——这是故意的，防止一个字打进两处。

## 七、出问题，按这个顺序查

| 现象 | 先查这个 | 怎么解决 |
|---|---|---|
| 一直转圈打不开 | **手机上 Tailscale 连了吗？** | 打开 Tailscale App，点一下连接 |
| 主入口打不开 | 换**备用入口**（数字地址那个）试 | 域名解析偶尔会抽，数字地址通常还能进 |
| 画面全黑 | 电脑锁屏或显示器睡了 | 让电脑上有人动一下鼠标 |
| 能看但点不动 | 顶上「控制」被关了 | 点一次「控制」重新打开 |
| 提示"今日超清 1 小时已用完" | 免费模式的超清配额用完了 | 正常现象：自动按高清出图，明天 0 点恢复；装许可证后不限时长 |
| 点不了管理员窗口 | 需要高权限注入 | 重启一次电脑；还不行找卖家 |
| 昨天还好今天不行 | 电脑重启过吗？有人登录吗？ | 电脑必须**登录着**（锁屏可以，注销不行） |
| 画面卡住不动 | 网络切换过（Wi-Fi↔4G） | 下拉刷新页面 |

### 自己解决不了的时候

双击桌面「手机远程」文件夹里的 **「自查」**，它会：
1. 检查 18 项，告诉你哪有问题
2. 每一项都说"你该做什么"
3. 生成一份报告存到 `手机远程\报告\`

**把那份报告发给卖家，比描述半天现象快得多。**

**第一次装好会先送 7 天全功能试用**：这 7 天按**专业版**算——超清不限时长、个性化全开、同时观看不限台数。
试用到期后自动回落到下面的**免费版**，画面不会被锁，基础功能一直免费。

打开 **设置（⚙）最上方的「许可证」分区**，第一行就是你现在是什么版本：

- 绿色徽章「**专业版**」= 已经装了许可证（会有有效期，永久就写"永久"）
- 蓝色徽章「**体验版**」= 买了 1 个月全功能（¥10）；有效期里会写"还剩几天"，到期自动回免费版

**体验版 = 1 个月的专业版**：下面那张表里"专业版"那一列的功能都能用，区别只是到期时间。
每台电脑最多买 3 次体验版（按机器码核对，续期前可以问一下卖家）。

**不装许可证就能直接用**（免费版），装了解锁更多：

### 另一种做法：用文件

如果卖家直接给了你一个 `licence.json` 文件：

1. 把它放到 `C:\Users\你的用户名\AppData\Local\PhoneAccess\`
   （最省事：`Win+R` 粘贴 `%LOCALAPPDATA%\PhoneAccess` 回车，直接把文件拖进去）
2. 文件名必须**正好是** `licence.json`
   ⚠️ 最容易犯的错：被存成了 `licence.json.txt`。在资源管理器里勾上「查看 → 文件扩展名」就能看出来

### 不装许可证会怎样

**一切照常能用**，只有两点限制：超清画质每天 1 小时（用完自动切高清，明天 0 点恢复）、设置里的个性化锁定。**画面不会被拦。**

### 换电脑怎么办

许可证绑机器。换电脑需要重新申请（按新单或另行报价）。
**换硬盘、重装系统不影响**（我们只用 CPU 和主板序列号，没绑硬盘）。

## 九、四条安全提醒

1. **二维码和网址里的 `k=` 是万能钥匙。** 拿到它的人能看、能操作你的电脑。别截图发人、别贴在群里。
2. **怀疑泄漏了**：双击「手机入口」→ 选 2 → 换一把新密钥。换完所有旧链接立刻失效，重新扫一次二维码即可。
3. **远程时别做敏感操作**：有人在看屏幕的时候，别输入密码、别转账。要输的时候先退出。
4. **公司电脑不要装**：如果你这台是公司统一管理的，装了我们也没法保证能用。

**另外：许可证那段文字也别转发给别人。** 它只对你这台电脑有效，但没必要外传。

| 开机自启 | 自动（Windows 计划任务「DSH Phone Access」，登录后触发，每 2 分钟兜底重试） |
| 服务卡死了 | 有守护程序每 8 秒检查，卡住会自动重启 |
| 出问题了 | 双击「自查」 |
| 电脑重启后 | 登录 Windows 后约 10~60 秒自己起来（以前要等 2 分钟，2026-10-31 已改快） |

**你唯一需要主动做的**：电脑上始终有人登录着（锁屏没关系，但**停在登录界面/注销不行**）。
要重启后无人值守也能连，需要在 Windows 里开启「自动登录」（设置 → 账户 → 登录选项，或用 `netplwiz`）；
这会降低本机安全性，自己权衡。
