### 关于两个入口（重要）

「手机入口」会给你**两个地址**：

| | 长什么样 | 用来干什么 |
|---|---|---|
| **主入口** | `https://xxx.ts.net/?k=...` | **平时用这个**。加密传输，还能"添加到手机桌面"变成 App |
| **备用入口** | `http://100.x.x.x:8660/?k=...` | **主入口打不开时用这个**。数字地址不依赖域名解析，一定能连 |

**两个都要存到手机书签里。** 主入口偶尔会因为这个那个打不开，备用入口通常还能进。

## 二、装到手机桌面（用起来像 App）

用**主入口**那个 https 地址打开，然后：

**安卓**：浏览器右上角 **⋮** → **「安装应用」**（或「添加到主屏幕」）

**iPhone**：用 **Safari** 打开 → 底部**分享** → **「添加到主屏幕」**
（不能用微信内置浏览器，那里没有这个选项）

装好后桌面上有个图标，**点开没有地址栏，全屏显示**，跟 App 一样。

> 如果你看到的是 `100.x.x.x` 这种数字地址，那个装不成 App——要装 App 必须用 https 的那个。
>
> **没有 https 地址？** 说明这个 Tailscale 账号还没开 HTTPS（一次性设置）：
> 1. 电脑上打开 <https://login.tailscale.com/admin/dns>
> 2. 找到 **HTTPS Certificates** → 点 **Enable HTTPS**
> 3. 回到电脑，双击「启动」（或等 1 分钟，守护进程会自动重配）
> 4. 重新打开「手机入口」，就会多出 `https://<机器名>.ts.net/` 这个能装 App 的地址
>
> HTTPS 只是让手机能"安装到桌面"；不开也能用 http 看画面，只是不能装成 App。

## 三、界面上每个按钮干什么

打开后顶上有一排按钮：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **清晰** | 正常出画面（H.264 硬件编码 + WebRTC 直连），画质由设置里的「宽度 / 帧率 / 码率」决定 | 平时都用这个 |
| **流畅** | 低频兜底画面（浏览器不支持高清编码时自动用；连不上会自动切回清晰） | 一般不用手动点 |
| **全部屏幕** | 选择抓哪块屏 / 哪个窗口 | 多显示器，或只想看某一个软件 |
| **桌面** | 一键最小化所有窗口 | 想快速找到桌面上的东西 |
| **声音** | 开/关电脑声音转发 | 需要听声音时 |
| **控制** | **总开关**。关掉后只能看，点不动 | 只想看不小心点错时，先关掉它 |
| **输入** | 打开打字面板 | 需要输入文字时（见下面第四节） |
| **命令** | 在电脑上执行 PowerShell 命令 | 高级功能，不懂别碰 |
| **设置**（右下角 ⚙） | 画质（宽度/帧率/码率）、个性化、许可证、版本信息 | 见下面「设置里的画质」和第八节 |
| **关于**（右下角 ❤） | 免费说明、机器码、分享给朋友 | 想了解功能或发给朋友时 |

### 设置里的画质（右下角 ⚙ →「画质与流量」）

一共三个下拉，**改完立刻生效**（不用重启，也不会掉线）：

| 项目 | 可选值 | 说明 |
|---|---|---|
| **宽度** | 1600 / 1920 / 2560 | 发到手机上的画面宽度。文字多（代码、表格、小字）选 2560 更清楚；流量紧就选 1600 |
| **帧率** | 30 / 60 / 90 / 120 / 240 | 越高越跟手，也越吃手机解码和带宽。240 需要手机和显卡都跟得上 |
| **码率** | 3 ~ 100 Mbps | 决定清晰度和流量：同样静止画面，码率低的会糊、快速变化时会花 |

- **流量 ≈ 码率 × 0.45 GB/小时**（1000 kbps 约 0.45 GB/时，20 Mbps 约 9 GB/时，50 Mbps 约 22 GB/时）。
  设置里会直接按你选的码率算好显示，不用自己算。
- **电脑弱会自动降档**：程序会检测这台电脑有没有硬件编码、能不能用桌面复制抓屏。
  没有硬件编码就自动封顶到 30fps / 12Mbps / 1600 宽；抓屏不可用则停用清晰模式。
  设置页底部会写明这台电脑的实际判定，**不用自己试**。
- 想让画面更糊一点省流量：把**码率**调到 6~10 Mbps 就够了（宽度和帧率不用动）。
- 手机屏会把画面压到屏幕宽度，所以 1600 和 1920 在正常距离看差别不大；**差别主要在文字密集的界面和流量**。
- **双指手势是滚轮，不是网页缩放**；两指一落下，光标会自动跑到两指正中并**固定在那里**，直到双指全部抬起。
- **三指及以上捏合/张开 = 缩放**：以所有手指的中心（手心）为缩放中心。顶部「缩放」折叠窗里可以切换：
  - **系统缩放**：给电脑发 `Ctrl+滚轮`，由电脑里的浏览器/资源管理器/Office 自己放大；不支持该快捷键的窗口无效。
  - **画面缩放**：只放大手机上的显示，电脑画面不变（光标会同步跟到手心）；放大后画面左侧出现「恢复原大小」，点它回到原始大小，
    回到正常大小时按钮自动消失。放大后仍可正常点按、拖动、双指滚动，点击位置会换算回放大后的画面。
  想看更细也可以选超清档；或者用手机系统的放大功能（iPhone：辅助功能 → 缩放；安卓：无障碍 → 放大手势）。

## 四、⚠️ 用手机流量看之前，务必先看这一节

**这不是提示，是会花钱的事。** 下面每个数字都是实测值，不是估算。

### 各种码率的实际流量

| 现在的画质 | 每小时流量 | 什么时候用 |
|---|---|---|
| **码率 20 Mbps（手机流量推荐上限）** | **约 9 GB** | 手机流量看文档/操作，够用且不算太狠 |
| **码率 6~10 Mbps** | **约 2.7~4.5 GB** | 手机流量、只想看个大概 |
| **码率 50 Mbps（默认）** | **约 22 GB** | 只在**手机和电脑同一个 WiFi** 时用 |
| **码率 100 Mbps** | 约 43 GB | 局域网 + 超大屏，看视频/设计稿 |

### 为什么流量差异这么大

清晰模式是**硬件编码的 H.264 视频流**（不是截图），码率就是每秒的数据量：

```
50 Mbps ≈ 6.25 MB/秒 ≈ 22 GB/小时
20 Mbps ≈ 2.5  MB/秒 ≈  9 GB/小时
```

**30 GB 的月套餐，用默认 50 Mbps 看一个多小时就没了。**

### 用手机流量时怎么设

打开设置 →「画质与流量」，把**码率调到 6~10 Mbps**（宽度 1600、帧率 30 也一起降更省）。
设置里会实时显示"当前码率约多少 Mbps、满速约多少 GB/小时"，按那个数字选就行。

想更省还可以开「自动」：它会按丢包和延迟自己降/升码率（6~20 Mbps 之间）。

### 一句话记住

> **在家用 WiFi → 码率留在 50 Mbps（或更高），打开「自动」也行。**
> **出门用流量 → 码率调到 6~10 Mbps（宽度 1600、帧率 30 更省）。**
> **只想扫一眼 → 码率 3~6 Mbps，够看清大概。**

### 如果画面不对（黑屏 / 卡住）

页面自己会重连；**实在不行点一下抽屉里的「重新连接」**（相当于刷新一次，会重建会话）。
如果设置页底部写着"这台电脑已按设备能力限制画质"，那是程序自动降档，属于正常保护，不是故障。

## 五、输入文字（这里最容易卡住）

### 方式一：文字面板（最稳，推荐）

1. 点顶上的 **「输入」**
2. 在面板里打字（支持中文、表情）
3. 点 **「发送」**

文字会一次性打进电脑上**当前光标所在的位置**。

⚠️ **发出去之后收不回来。** 就像有人在电脑前把这段话打进去了一样——打错了只能在电脑那边删。

### 方式二：特殊键按钮

「输入」面板下面有一排键：

```
退格  删除  回车  Esc  Tab
 ←     ↑     ↓     →
     撤销(Ctrl+Z)
```

- **退格 / 删除**：删字，不用回电脑前
- **回车**：确认、换行、发消息
- **方向键**：移动光标
- **撤销(Ctrl+Z)**：**只对支持撤销的软件有效**（记事本、Word、浏览器），很多软件里没用

### 方式三：接蓝牙键盘（装了 App 才有）

打开 App 后接蓝牙键盘，**打字会实时出现在电脑上**，跟坐在电脑前一样。

> 注意：光标在手机上的输入框里时，按键不会传给电脑——这是故意的，防止一个字打进两处。

## 七、出问题，按这个顺序查

| 现象 | 先查这个 | 怎么解决 |
|---|---|---|
| 一直转圈打不开 | **手机上 Tailscale 连了吗？** | 打开 Tailscale App，点一下连接 |
| 主入口打不开 | 换**备用入口**（数字地址那个）试 | 域名解析偶尔会抽，数字地址通常还能进 |
| 画面全黑 | 电脑锁屏或显示器睡了 | 让电脑上有人动一下鼠标 |
| 能看但点不动 | 顶上「控制」被关了 | 点一次「控制」重新打开 |
| 画面突然变糊了 | 手机流量/信号差时服务端会降档 | 网络恢复后会自动升回；也可在设置里手动选高档 |
| 点不了管理员窗口 | 需要高权限注入 | 重启一次电脑；还不行找卖家 |
| 昨天还好今天不行 | 电脑重启过吗？有人登录吗？ | 电脑必须**登录着**（锁屏可以，注销不行） |
| 画面卡住不动 | 网络切换过（Wi-Fi↔4G） | 下拉刷新页面 |

### 自己解决不了的时候

双击桌面「轻屏」文件夹里的 **「自查」**，它会：
1. 检查 18 项，告诉你哪有问题
2. 每一项都说"你该做什么"
3. 生成一份报告存到 `轻屏\报告\`

**把那份报告发给卖家，比描述半天现象快得多。**

## 八、完全免费（许可证是可选项）

**这个产品现在完全免费**：不装许可证也能用，没有广告、不用注册账号、没有倒计时或限时。

| 功能 | 免费版 | 装了许可证（可选） |
|---|---|---|
| 画面、触控、声音、打字、命令、剪贴板、大文件传输 | ✓ 不限时 | ✓ |
| 流畅模式 / 高清 1920 / 超清 2560 | ✓ 都不限时 | ✓ |
| 个性化（配色主题、光标形状 / 大小 / 颜色、自定义导入） | ✓ 全开 | ✓ 全开 |
| 同时观看的设备数 | 不限（多少台都行） | 不限 |

- 机器码 = 这台电脑的指纹（CPU + 主板），在「设置 → 许可证」里，点「复制」就能拿走。
  换电脑时用它找回自己的设置；换硬盘、重装系统不会变。
- 许可证**绑定这一台电脑**，是可选项：装上只是解锁个性化与更多设备，平时不看也不影响任何功能。

### 粘贴许可证（一分钟）

1. 设置（⚙）→「许可证」分区 →「已有许可证？粘贴到这里激活」
2. 把许可证整段**原样粘贴**进去 → 点「验证并安装」
3. 提示"好了"会自动刷新，徽章变成「已授权」

> 一段很长的字母数字、或 `{` 开头的花括号内容，两种都能粘，页面会自己识别。

### 分享给朋友

右下角 ❤（关于）→ 面板最下面「分享给朋友」：

- 点「复制分享文案」发给朋友，或用「用系统分享…」直接弹微信 / QQ / 短信；
- ⚠️ **只发这段文案**。别把页面上那条带 `k=` 的完整地址发出去 —— 那是你这台电脑的钥匙，
  谁拿到都能看你的屏幕。分享文案里只有下载页链接，是安全的。

### 另一种做法：用文件

如果手上有 `licence.json` 文件：

1. 把它放到 `C:\Users\你的用户名\AppData\Local\PhoneAccess\`
   （最省事：`Win+R` 粘贴 `%LOCALAPPDATA%\PhoneAccess` 回车，直接把文件拖进去）
2. 文件名必须**正好是** `licence.json`

## 九、四条安全提醒

1. **二维码和网址里的 `k=` 是万能钥匙。** 拿到它的人能看、能操作你的电脑。别截图发人、别贴在群里。
2. **怀疑泄漏了**：双击「手机入口」→ 选 2 → 换一把新密钥。换完所有旧链接立刻失效，重新扫一次二维码即可。
3. **远程时别做敏感操作**：有人在看屏幕的时候，别输入密码、别转账。要输的时候先退出。
4. **公司电脑不要装**：如果你这台是公司统一管理的，装了我们也没法保证能用。

**另外：许可证那段文字也别转发给别人。** 它只对你这台电脑有效，但没必要外传。

## 十、日常维护（其实不用管）

| 事情 | 谁管 |
|---|---|
| 开机自启 | 自动（Windows 计划任务「DSH Phone Access」，登录后触发，每 2 分钟兜底重试） |
| 服务卡死了 | 有守护程序每 8 秒检查，卡住会自动重启 |
| 出问题了 | 双击「自查」 |
| 电脑重启后 | 登录 Windows 后约 10~60 秒自己起来（以前要等 2 分钟，2026-10-31 已改快） |

**你唯一需要主动做的**：电脑上始终有人登录着（锁屏没关系，但**停在登录界面/注销不行**）。
要重启后无人值守也能连，需要在 Windows 里开启「自动登录」（设置 → 账户 → 登录选项，或用 `netplwiz`）；
这会降低本机安全性，自己权衡。
