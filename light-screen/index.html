FIG.03功能

它跟常见远控不一样的地方

这几条是我做它的理由，也是它比大厂那套更直接的地方。

01

手机不用装 App

浏览器直接开（Tailscale 是网络层，必须先装），还能「添加到主屏幕」当 App 用；换台手机打开网址就行。想要小窗、画中画、后台保活，再装那个 41 KB 的安卓 App（可选，不是必需）。

02

不过远控厂商的服务器

画面走自己的加密网（Tailscale 点对点），我这边收不到你的画面。

03

同网直连很快

同一个 Wi-Fi 下 Tailscale 会走直连（不是中继）；传大文件走满 Wi-Fi（单文件 20GB，断点续传）。手机传来的文件会落在电脑的下载目录，位置可以改，也能在电脑上一键打开那个文件夹。

04

最高 240fps

硬件编码（NVENC）+ WebRTC 直连，同网缓冲常在 10ms 上下，鼠标跟手。画质上限 240fps / 100Mbps / 2560 宽，发布版不再比自用版低一档。

05

该有的都有

多指缩放、文本剪贴板互通、命令面板、防窥屏、长按=右键、双指滑动=滚轮、三指以上=缩放。

06

完全免费

没有专业版、没有免费额度、不要账号。源码在明处，改动随意，商业用途需要先谈。

v1.0.24 这版修的是1.0.23 里手机端工具条消失的严重 bug（只看到画面、点不了声音/控制/更多）；同时在「设置 → 画质与流量」里加了HEVC 状态与「重试 HEVC」按钮，并把弱网下的解码器重建问题修掉（3% 丢包掉帧 11% → 6.9%）。改动明细都在更新记录里。

FIG.05怎么用

电脑端装一次，之后手机上打开网址就能连

三步，大约 5 分钟（装 Tailscale 那一步看网速）。

  1. 第一步

    电脑装轻屏

    Windows 10/11，双击安装包，装完桌面会出现「轻屏」文件夹。

  2. 第二步

    手机装 Tailscale，登录同一个账号

    必须装，同一个 Wi-Fi 也一样：轻屏只对 tailnet 开放（安全设计）；同一 Wi-Fi 下会直连，很快。

  3. 第三步

    手机打开网址

    扫桌面文件里的二维码或直接输地址，就能看屏幕、操作。建议「添加到主屏幕」。

FIG.08问题

常见问题

先看这几条，多半能省一次往返。

要装 App 吗？

不用。手机浏览器打开网址就能用；想更像 App，可以在浏览器菜单里「添加到主屏幕」。

画面经过你的服务器吗？

不经过。默认走 Tailscale 的点对点加密通道（直连或 Tailscale 自己的中继），我这边没有你的画面和文件。

为什么第一次打开提示「不安全」？

用 IP 直接打开（自签证书）会这样，点「高级 → 继续前往」即可；用 Tailscale 的域名地址不会提示。

支持哪些系统？

电脑端只支持 Windows 10 / 11（Mac / Linux 以后再说，不承诺时间）；手机端两种都行：浏览器直接打开，或者装 41 KB 的安卓 App（多出小窗、画中画、后台保活、音量键、高刷）。

能拿来商用吗？

需要先和作者谈。协议是 PolyForm Noncommercial 1.0.0：允许改、允许自己用、允许分享，但商业用途要事先获得书面同意。
