# 轻屏 1.0.18 更新说明

> 产物：`LightScreen-Setup-v1.0.18-selfuse.exe` / `-release.exe`（未发布，等你确认）
> 日期：2026-11-08

## 面向使用者的变化

**画面**
- 修复清晰模式在 2560 宽（超清/原生分辨率）时"能操控但黑屏"：某些显卡/ffmpeg 组合不支持
  GPU 零拷贝，现在启动时自动探测，不可用就走缩放路径；另加"连续秒退自动回退"兜底。
- 同一 Wi-Fi / Tailscale 下清晰模式稳定 2560×1600@60fps（实测缓存 12–14ms）。
- 流畅 ⇄ 清晰切换时，顶部按钮状态终于跟着变了（以前从流畅切回清晰，标签还停在"流畅"）。
- 清晰模式万一 8 秒（已连上则 15 秒）仍无画面，自动退回低频画面，不再一直黑着。

**串流玩游戏（Moonlight）**
- 新增独立开关「**允许同一 Wi-Fi 串流**」：只放行 Sunshine 自己的端口，
  程序限定 `Sunshine.exe`、来源仅局域网私有网段；关掉立即恢复"只允许 Tailscale"。
- Sunshine 管理后台（47990）不再对局域网开放：后台按钮/备用配对改为通过 Tailscale 地址打开。

**定时开关机**
- 修复"点『加入』永远提示时间格式不对"（页面正则把 `\d` 写成了字母 `d`）。
- **定时唤醒真正可用了**：唤醒任务改为以 SYSTEM 身份注册（以前普通用户身份注册的闹钟，
  固件不兑现，到点不醒）。实测：23:00 休眠 → 次日 06:59:46 由定时器唤醒。
- 唤醒任务带 +3/+6 分钟冗余触发；面板新增「自检：2 分钟后休眠 · 4 分钟唤醒」。
- 自用版新增「唤醒后不要求登录」（发布版强制关闭）+ 手机「立即锁屏」。

**稳定性**
- 开机自启时 Tailscale 常常还没就绪（以前会出现"服务像没自启"）：守护进程现在会周期
  重新发现 tailnet 地址并自动重绑，不再反复空重启。
- 画面服务自愈补齐：Pion 视频会话也算"有观众"，capture 卡死能被重新拉起。

**安全与体验**
- 防火墙放行全部收紧为「程序级 + 仅私有网段」；不放行 47990、不放行公网。
- 页面缓存（Service Worker）换了新版本号并会自动清理旧缓存；设置顶部显示「页面版本」，
  以后"修好又复发"先看它是不是旧页面。
- 音频采集改为 10ms 分块 + 20ms 缓冲（声音更跟手一点）；音画差结论已实测归档。

## 隐私与安全审查补丁（2026-11-08 下午，已重打包）

对发布包做了逐项审查（详见 `docs\发布审查-2026-11-08.md`），修掉四处：

1. **二维码库泄露构建机信息**：包里的 `qrlib\bin\qr.exe` 内嵌
   `C:\Users\<构建机>\.dsh\...\python.exe`，65 个 `.pyc` 也带构建机绝对路径。
   → 打包时清掉 `qr.exe` / `__pycache__` / `.pyc`，并加断言（qrlib ≥50 文件、`.pyc` 禁止进包）。
   二维码功能实测正常（`make-qr.py` 出 420×420 PNG）。
2. **声音/输入组件里的 `dsh-audio` / `dsh-input` 默认名**：重编译 `audio.exe` / `input.exe`
   为 `pa-audio` / `pa-input`（脚本早就用 `pa-*`，功能不变；只是去掉 DSH 字样）。
3. **pnpm `.bin` 垫片带构建机绝对路径**：打包时统一删除（发布版原就有后处理，自用版下次打包生效）。
4. **发布版「唤醒后不要求登录」开关**：服务端 `/power/apply` 在 release 下一律写 false；
   页面按 `profile` 隐藏该开关（防旧缓存/直接调接口绕过），页面版本升到 `2026-11-08.1`。
