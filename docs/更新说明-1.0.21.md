# 轻屏 v1.0.21 更新说明

> 发布日期：2026-11-10
> 安装包：`LightScreen-Setup-v1.0.21-release.exe`（体积见安装包）

## 这次改了什么

### 修好了「画面大幅变化时偶尔花屏」

典型场景：**突然把某个窗口全屏、或者最小化一个窗口**时，画面会花一下/卡一下。

原因找到了：画面整块换内容时，编码器会吐一个特别大的帧（实测单帧 688 KB ≈ 600 个数据包，是平时的 8 倍），
这一帧在手机网络上丢任意一个包，整帧就坏了 —— 而它恰好是"画面变了"的那一帧，所以花屏总是跟着大幅变化出现。

这次做了三件事：

- **丢包后立刻停手等关键帧**：以前要等 2 秒的统计周期才发现丢包，现在 0.6 秒就反应，
  把"花一片"变成"最多停半秒"。
- **重传缓存加大 4 倍**（1024 → 4096 个包）：网络稍微抖一下，缺的那点数据能补回来。
- **修好了一个更根本的 bug**：切换分辨率（高清↔超清）时，接收端解码器没跟着换参数，
  会一直用旧参数解新画面 → 表现就是画面冻住/花屏。现在会自动重建解码器。

### 新增「设备审查」：弱电脑不会再黑屏

启动时会自动检查这台电脑能不能跑清晰模式，**只降档、不阻断**：

| 检测结果 | 程序怎么做 |
|---|---|
| 有显卡硬件编码 + 抓屏正常 | 一切照旧（画质上限和自用版完全一样） |
| 没有可用的显卡硬件编码 | 自动限制到 **30fps / 12Mbps / 1600 宽**（软件编码带不动更高） |
| 抓屏/编码组件不可用（虚拟机、远程桌面等） | 自动停用清晰模式，走低频画面，并在设置里说明原因 |

以前遇到这类机器会反复启动编码器、黑屏等很久；现在直接给出合适档位。
设置 →「画质与流量」底部会显示这台电脑的实际判定。

### 画质上限不再分「自用版 / 发布版」

以前发布版的上限被压在 60fps / 40Mbps。现在**两个版本一样**（最高 240fps / 100Mbps / 2560 宽），
扛不住的机器交给上面的「设备审查」自动处理。

### 去掉「画质优先」开关

它的说明写着"文字更锐、延迟约 +1 帧"，实测**静态画面看不出差别，而延迟和显卡占用真的会涨** ——
说明和实际不符，与其写一句糊弄人的话，不如直接去掉。默认就是低延迟档。

### 其他修复

- **首次连接更快**：以前每次连上都白丢约 45 帧（黑半秒），现在基本不丢。
- **切「超清」不再白黑 2~4 秒**：以前每次切到 2560 宽都会去试一条走不通的零拷贝路径，
  失败两次才退回。
- **卡住不再永久放弃**：画面卡住时先自动重建接收端（最多 3 次），实在救不回来才回退，
  不会像以前那样一次卡顿就永久退到"延迟会涨"的老链路。
- **流量提示不再写死**：以前固定写"约 8.9GB/小时"，现在按你实际选的码率计算。
- **修好"声音越听越不同步"**：以前声音会相对画面越拖越慢（实测每 2~5 分钟偏 3 秒然后"跳"一下）。
  根因是音频采集的采样时钟和电脑系统时钟有约 ±1‰ 的频差；现在采集端会**自动微调采样率**把它吸收掉
  （重采样比变化极慢，听不出来），同时把音频节拍精度从 15ms 提到 1ms。实测音画两条时间轴
  每秒都走 1000ms、误差稳定在 ±10ms 内，不再漂。
- **修好"越看越卡、帧率显示静止"**：手机端解码跟不上时，解码队列以前会无限堆积
  （实测攒到 1481 帧 ≈ 25 秒，画面越拖越慢）。现在队列一深就自动清空重来、并且**自动把帧率降到
  这台设备吃得下的档位**；HUD 的帧率也改成按"实际画出来的帧"算，不会再出现画面在动却显示「静止」。

### 「关于」面板重做，多了 B 站入口

设置 →「关于」现在一眼能看到这版修了什么；下面新增**作者 B 站卡片**，点「去 B 站关注支持」直接打开
教程主页（下载 / 安装 / 使用都有视频，更新也会发）。面板里的「分享给朋友」文案也一起重写了。

### 传文件：能看见、也能改保存目录

以前手机传过来的文件只显示文件名，你根本不知道存哪了 —— 现在「设置 → 功能 → 传文件」里直接写着
**保存到 `C:\Users\你\Downloads\PhoneAccess`**，还有两个按钮：

- **在电脑上打开**：直接在电脑上弹出资源管理器定位到那个文件夹；
- **更改位置**：填一个绝对路径（例如 `D:\手机传文件`），以后手机传的文件就存那里，重启也记得。

### 两台设备同时用，不再互相打断

以前任何一台设备调画质，服务端都会**无条件重启编码器**，另一台画面就黑 1~2 秒；两台设置不同时更会来回打断。
现在参数没变就不重启。另外「WebRTC 连不上」的回落标记以前是**永久**的（回落一次就再也连不回来、
必须杀掉页面重进），现在 10 分钟后自动重试，点「重新连接」也会立即重试。

## 升级方式

**直接装新的安装包就行**，会覆盖旧版本，不需要先卸载：

- 许可证会保留（不需要重新授权）
- 画质设置会保留
- 安装目录：`%LOCALAPPDATA%\PhoneAccess`

## 已知事项

- 首次安装需要管理员权限（会弹一次 UAC，点「是」）
- 装完建议重启一次电脑再连，确认"重启后还能连"才算真的装好
- 硬件特别弱的电脑（无显卡硬件编码）会自动用较低画质，这是正常的保护行为，不是坏了

## 出问题怎么办

双击桌面「轻屏」文件夹里的「**自查**」，它会生成一份报告，把这个报告文件发给卖家即可。
