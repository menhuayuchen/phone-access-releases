# 上一轮 14 条的修法 + 本轮新增

## 一、上一轮你提的 14 条（全部已修并实测）

| 编号 | 问题 | 修法（文件:位置） |
|---|---|---|
| **H1** | Tailscale serve 使 remoteAddress 恒为 127.0.0.1，本机豁免被穿透，未授权可盲控 | 鉴权重分三层（见 `01-系统事实.md` 第三节）；`screen-server.mjs` 的 `authorized()` / `STRICT_AUTH_PATHS` / `LICENCE_OPEN_PATHS` |
| **H2** | 窗口标题进 `innerHTML`，浏览器窗口标题可被恶意网页控制 → XSS | `page.mjs` 的 `rebuildSourceOptions()` 改用 DOM API（`createElement` + `textContent`），不再拼字符串 |

| **M2** | 软停对 `/frame.jpg`、`/stream` 不生效 | 缓存键从 `Math.max(stateMtime, liveMtime)` 改成复合键 `stateMtime\|liveMtime`（原键在删掉 licence.json 后不变） |
| **M3** | 防火墙只覆盖部分网段 | `install.ps1` **允许 `100.64/10`（tailnet）并拒绝三块 RFC1918**；配合 `screen-server.mjs` 新增的绑定地址白名单（只绑回环/私有/tailnet），实际行为安全 |
| **M4** | `/exec` 可被跨站提交 | 要求密钥 + `application/json`（简单请求无法带这个 Content-Type，绕过需要预检） |
| **L1** | `/health` 泄露前台窗口标题 | `fg=` 和 `input.foreground` 只给带密钥的请求 |
| **L2** | Origin 检查可被非浏览器伪造 | 记录为低风险：仍需密钥 |
| **L3** | `machine.id` 可写 | 记录为接受的取舍（目标是防随手转发） |
| **L4** | 桌面快捷方式静默失败 | `New-DesktopShortcut` 记录失败原因；三级兜底（用户桌面 → 公共桌面 → 安装目录）+ `.cmd` 兜底 |
| **L5** | 安装器对已清零文件误判为成功 | robocopy 加 `/IS`；复制后**逐文件验内容**（大小 + 前 16 字节 + 脚本类整文件哈希） |
| **M5/L6** | 文档与实现不符 | 说明书里的模式参数、流量数字已按实测更正 |

## 二、本轮新增的功能

| 功能 | 文件 | 说明 |
|---|---|---|
| 手机端设置面板 | `page.mjs` | 齿轮+心形两个按钮（纵排贴右边）；面板内分卡片显示许可证/机器码/连接/版本 |
| 检查更新 | `screen-server.mjs` `/update-check` + `page.mjs` | **只有客户点按钮才联网一次**；更新源地址来自服务端配置，**不接受客户端传 url**（因此不构成 SSRF 跳板） |
| 一键卸载 | `uninstall.ps1` / `uninstall.cmd` | 六步撤干净；**默认保留许可证**；有二次确认（要输入 YES）；**有开发目录保护**（检测到 `pack.ps1` 等就拒绝执行） |
| 重启服务 | `restart.ps1` / `restart.cmd` | 停 → 起 → 验收三步 |
| DSH 端口自动发现 | `dsh-port.ps1` | 用 401 响应体指纹（`dsh web authentication`）识别 DSH 网页端口；**只用于诊断提示，不参与选端口** |
| 画质档位 | `screen-server.mjs` `/set-quality` | 写 `maxCaptureWidth`。**目前 UI 已隐藏**，见 `03-已知问题.md` 第 1 条 |
| 桌面文档 | `install.ps1` | 安装时把 `使用说明.md` 复制到桌面文件夹 |

## 三、本轮我自己引入、又修掉的 bug（供你参考我的错误模式）

| bug | 表现 | 根因 |
|---|---|---|
| 内容校验误报 | 装过旧版的机器，第 4 步必失败「内容与安装包不一致：product.config.json」 | 我一边**刻意不覆盖**客户配置，一边又要求它等于出厂值 |
| 老配置缺新字段 | 升级上来的机器看不到版本号、检查更新失效 | 保留旧配置但没做字段迁移；已加"只增不改"的迁移 |
| 端口冲突误报 | 服务在跑时再启动 → 报"8660 被其它程序占用"并退出 | `Get-PortOwner` 只读 `CommandLine`，而 detached 启动的 node 命令行读不到 → 把自己的进程当外人 |
| 自适应降速死循环 | 切分辨率后帧率掉到 9 帧 | `restartImg()` 造成的丢帧被当成网络拥塞 → 降档 → 再丢帧。已加两道守卫：宽度变化整轮跳过、连续两轮拥塞才降档 |
| 许可证强制重算从未生效 | M1 的修复形同虚设 | `licence-state.ps1` 的 `param` 里**没有 `-Force`**，而调用方传了它 → 参数错误被 catch 吞掉，`$Force` 恒为 `$null` |
| 帧率回退 | 高清从 24 掉到 9 | 为了恢复 DSH 网址打开了 `enableDsh`，多跑一个 408MB 的 DSH web 抢 CPU。抓屏是纯 CPU 活，被抢就掉帧 |
