## 四、审查建议的优先级

1. **鉴权**——上一轮的 H1（Tailscale serve 导致 remoteAddress 全是 127.0.0.1，本机豁免被穿透）就出在这里，是风险最高的地方
2. **许可证验证**——Node 侧验 RSA 签名的实现
3. **`install.ps1`**——1907 行、以管理员权限运行、要改防火墙/计划任务
4. **`uninstall.ps1`**——破坏性操作
5. **本轮新增的接口**——`/set-quality`、`/update-check`、`dsh-port.ps1`（会做网络探测）
