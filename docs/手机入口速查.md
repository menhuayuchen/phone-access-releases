## 二、每一条的注意事项

### 1. DSH（`<本机Tailscale地址>:8642`）

**怎么进最省事**：书签只存 `http://<本机Tailscale地址>:8642/`（**不带 `k=`**）

| 情况 | 行为 |
|---|---|
| 这台手机 7 天内登录过 | 自动跳转，直接进 |
| 没登录过 / 过期了 | 出现「需要重新登录」页，**按钮里已经带着真密钥**，点一下就进 |

**要点**

- 手机和电脑看到的是**同一份数据**：同一个工作区、同一个会话库、同一份 API Key。手机上发的消息，电脑上接着看得到。
- DSH 每次重启都会换登录令牌，但 `/go` 链接永远不变（所以推荐用它，不要存 `?token=` 那种链接）。
- 电脑端 DSH 挂了会显示「DSH 没有在运行」，supervisor 会自动拉起，等 15 秒刷新即可。
- **密钥位置不能有省略号**：`k=` 后面必须是 16 位字母数字。如果复制时带上了 `…`，会看到「这个链接不完整」（这是我今天新加的判断，就是为了不再让你猜）。

### 2. 屏幕共享（`<本机Tailscale地址>:8660`）

**第一次必须带 `?k=`**，浏览器会存一个一年期的 cookie，之后只输 `http://<本机Tailscale地址>:8660/` 也能直接进（实测：带密钥 200 → 之后不带也 200）。

**能做什么**

- 实时画面（MJPEG 流，默认上限 22 fps）
- 点击 / 拖动 / 滚轮 / 键盘输入
- 「桌面」按钮（一键最小化全部窗口）
- 省流量模式、分辨率切换

**要点**

- 无密钥一律 **401**；同一个设备 10 分钟错 8 次 → **锁 10 分钟**（`screen-auth.log` 留痕）。
- 只能在 Tailscale 内访问，局域网已封。
- 电脑**锁屏 / 显示器睡眠**时画面会黑——这是系统行为，不是坏了。远程时最好在电源设置里关掉睡眠。
- 有时点不动：如果目标窗口是**以管理员权限运行**的，UIPI 会拦注入。这个项目的注入通道已经按管理员跑，一般不会遇到。

### 3. 录屏控制（`<本机Tailscale地址>:8780`）

**只有三个动作**：START、STOP、看状态（录了几秒、多大、文件名）。

**要点**

- 必须带密钥（今天刚加的；之前这个服务**完全没有密码**，局域网里谁都能点 START，已经修掉）。
- 录的是**整块屏幕**（2560×1600），会把你所有窗口一起录进去。录之前先想一下屏幕上有什么。
- 文件存在电脑的 `D:\dsh-rec\out\`，录完自动转成 mp4。
- **没有下载入口**（故意的），要拿文件得在电脑上拷。

## 三、三条红线

1. **只走 Tailscale。** 打不开时第一件事就是看手机上的 Tailscale 是不是连着（这是最常见的原因，比密钥问题多得多）。
2. **局域网入口已经封了**，这是你自己要的（`harden-firewall.ps1`）。想恢复要管理员执行 `-Undo`。
3. **密钥 = 这台电脑的全部权限**（能读文件、能跑命令、审批提示是关着的）。别截图发人、别贴在聊天里。万一怀疑泄漏：

```powershell
# 换密钥：立刻吊销所有旧链接 + 所有已登录设备
.\rotate-key.ps1 -Force
```

## 四、出问题先查这张表

| 手机上的现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 一直转圈、打不开 | Tailscale 没连 / 切换了网络 | 打开 Tailscale App 确认已连接 |
| 「访问密钥不对」 | 链接里的 `k=` 不是真密钥（多半是复制时带了 `…`） | 用本文档的链接，或只打开 `:8642/` 让页面给按钮 |
| 「这个链接不完整」 | 就是上面那种情况（`k=…`） | 同上 |
| 「需要重新登录」 | DSH 重启过，令牌失效 | 点页面上的按钮，不用扫码 |
| 「DSH 没有在运行」 | 电脑端实例挂了 | supervisor 会自动重启，等 15 秒刷新 |
| 「DSH 正在重启」 | 刚重启，令牌还没生成 | 页面会自己 10 秒后刷新 |
| 画面黑屏 | 电脑锁屏 / 显示器睡眠 | 电脑上动一下鼠标 |
| 画面卡住不动 | 网络切换（Wi-Fi ↔ 4G）后连接残留 | 下拉刷新页面 |
| 录屏页 401 | 没带 `?k=` | 用第 3 条那个完整链接 |
