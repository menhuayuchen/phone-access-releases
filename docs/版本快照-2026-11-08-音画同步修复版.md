## 3. 构建命令（这台机器）

```powershell
# 侧车（Go）
$env:GOPATH='D:\download\办共\phone-access-product\tools\gopath'
$env:GOCACHE='D:\download\办共\phone-access-product\tools\gocache'
$env:GOFLAGS='-mod=mod'; $env:GOPROXY='off'
cd app\rtc-h264; ..\..\tools\go\bin\go.exe build -o rtc-h264-new.exe .

# audio.exe（C#，csc 4.0 + netstandard 兼容程序集 + 生产的 NAudio）
$csc='C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe'
$lib='C:\Users\ccj\AppData\Local\PhoneAccess\lib'
$ns='C:\Windows\Microsoft.NET\Framework64\v4.0.30319\netstandard.dll'
cd app; & $csc /nologo /target:exe /optimize+ /out:audio-new.exe /r:$ns /r:$lib\NAudio.Core.dll /r:$lib\NAudio.Wasapi.dll /r:$lib\NAudio.WinMM.dll audio.cs
```
