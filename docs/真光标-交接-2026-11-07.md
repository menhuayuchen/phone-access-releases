# 真光标功能 · 交接说明（2026-11-07）

> 给接手发版/验收的会话或人看。这个功能已经合进 `master`，**默认开启**，不需要 URL 参数。
> 未发版（按规则 a293ad2e，发布需用户明确同意）。

---

## 一句话

手机上看远程桌面时，能看到**电脑上真实光标的位置和形状**（箭头 / 文本 I 形 / 手型 / 等待圈 / 调整大小），
而不是只有一个"跟着手指走的黄点"。

---

## 为什么要做

采集端是 `ddagrab=draw_mouse=0`——系统光标被从视频里剥掉了（这样视频更干净、避免光标拖影）。
代价是手机端**完全看不到电脑上的真实光标**：鼠标在动、卡住了、变成文本编辑状态，手机用户一无所知。

---

## 怎么用（给用户的说辞）

**设置 → 个性化 → 光标显示**，两个选项：

| 选项 | 说明 |
|---|---|
| 跟随手指（默认） | 老的黄点，点哪指哪 |
| 电脑真实光标 | 显示电脑上真实的箭头 / I 形 / 手型 / 等待圈 / 调整大小 |

规则：

- **两者互斥，任何时刻只有一个**
- 默认是黄点
- **接了鼠标会自动切到真光标**（只自动切一次，之后尊重手动选择）
- 选「电脑真实光标」时，下面的光标形状/大小/颜色三项会置灰（那只对黄点生效）

## 技术实现

### 服务端

| 文件 | 做了什么 |
|---|---|
| `app/input.cs` | 注入器的 `{t:'cursor'}` 回复扩展：加 `cs`（形状 id）+ `vis`（是否可见）。用 `GetCursorInfo` 拿 `hCursor`，再用 `LoadCursor(Zero, IDC_*)` 的共享句柄比较，识别 14 种标准光标；应用自定义光标一律回落 `arrow` |
| `app/input.mjs` | 轮询 400ms → **33ms**；`cursor()` 返回 `{x,y,s,v,at}` |
| `app/screen-server.mjs` | 新增 `/ws-exp` WebSocket：30Hz 推 `{t:'cur',x,y,s,v}`，位置没变不重发；`experiments.enabled=false` 时 404；未授权 403 |
| `app/product.config.json` | `experiments{enabled,cursor,ocr}`，`enabled` 目前是 `true` |

### 客户端

`app/page.mjs` 里的实验层（`expCursorStart` / `expInitMode`）：

- `#expCursor` 元素 + 12 个内联 SVG 光标（`EXP_SHAPES`，每个自带 `w/h` 和热点 `hx/hy`）
- **每帧**用 `toPage(st.rx, st.ry)` 重算位置（复用主线的坐标换算，不另写一套——这是 2026-11-06 触屏偏移事故的教训）
- 0.78 lerp 平滑，把 30Hz 采样补成视觉连续
- 尺寸：`clamp(画面宽度 × 2.8%, 11, 22)` CSS px，再乘 `view.scale^0.35`（放大时温和跟随，不变成巨物）
- 真假光标互斥靠 `body.expNoDot` + CSS `!important` 压制（主线是直接改 `dot.style.display` 内联样式的，普通规则压不住）

## 验证数据（实测）

- 注入器：回复含 `{cx,cy,cs,vis}`，实测拿到 `cs=progress`
- `/ws-exp`：正确密钥推送正常，错误密钥 **403**
- 坐标：`/input` 设点 → 注入器回读，`(100,100)`/`(1280,800)`/`(2400,1500)`/`(640,1200)` **delta 全为 0**
- 页面：`#expCursor` 的 `getBoundingClientRect()` 与 `toPage(1280,800)` 只差 1.3px（SVG 热点偏移，符合设计）
- 默认加载：URL 不带任何参数时 `window.__paExp.on.cursor === true`

## 已知限制

1. **`input.exe` 需要重新编译部署才能看到形状变化**。形状识别在 `input.cs` 里，而线上注入器是
   `C:\Program Files\PhoneAccessInput\input.exe`（High 完整性）。没替换时：位置正常、形状固定为箭头
   （`input.mjs` 对缺失的 `cs` 回落 `arrow`，是设计好的降级）。
   替换方式：编译 `input.cs` → 复制成 `app\input.exe` → 管理员权限跑 `app\install-elevated-input.ps1`。
2. **应用自定义光标**（Chrome 的文本光标、游戏、Electron）一律显示为箭头。
3. **光标在副屏时**没有做"是否在采集区域内"判断，单显示器无影响。

## 同批次里还有一个实验功能（默认关，不进正式版）

**高清放大增强**（`?exp=ocr` 才加载，设置里有开关）：

画面放大到 1.25 倍以上并停手时，向服务端要这一块的原生像素 JPEG（服务端抓 2560×1600 原始帧，
不是 1920×1200 的视频），贴到页面上盖住视频层。实测 1400×1000 区域 60ms / 300KB。

**限制**：贴的是静态快照 → 动态内容（视频、滚动）会冻住；拖动时只能先藏起来。
用户判断「只适合静态内容（文档/代码/聊天记录）」。**不建议进正式版**。
