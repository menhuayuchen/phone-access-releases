# 主安装包与可选组件 · 下载与说明（2026-11-04）

> 背景：蓝奏云/部分网盘单个文件上限 **100 MB**。带网页端 H.264 后主包约 **87.5 MB**，
> 所以「高性能模式（Moonlight）」的 Sunshine 组件改为**单独下载**，两个文件各自都在限制内。

## 一、主安装包（必装）

| 项 | 内容 |
|---|---|
| 文件名 | `PhoneAccess-Setup-v1.0.x.exe`（单文件，自解压安装） |
| 体积 | 约 **87.5 MB**（含网页端 H.264 组件 `bin\ffmpeg.exe`） |
| 包含 | 网页模式（MJPEG + H.264 高清）、Tailscale 安装包、节点运行时、许可证/试用 |
| 不含 | Sunshine（高性能模式）组件、Moonlight 客户端 |

安装：双击 → 按提示（管理员授权）→ 手机扫二维码即可用。
网页端清晰模式会自动优先 H.264（MSE），浏览器不支持或组件缺失时自动回落 MJPEG。

## 二、可选组件：高性能模式（Moonlight / Sunshine）

| 项 | 内容 |
|---|---|
| 文件名 | `Sunshine-Windows-AMD64-installer.msi` |
| 体积 | 约 **32 MB** |
| 许可证 | **GNU GPL v3**（独立程序，未修改源码） |
| 上游 | https://github.com/LizardByte/Sunshine （发布页同仓库 Releases） |
| 用途 | 电脑端串流服务（Moonlight 客户端连接用），低延迟/高帧率通道 |
| 依赖 | 手机另装 **Moonlight** 客户端（安卓：GitHub `moonlight-stream/moonlight-android` releases；iOS：App Store） |

安装方式（任选其一）：
1. 主安装包安装时如果检测到该组件文件在同一目录，会自动安装并预配置（只绑 tailnet、随机密码、防火墙收紧）；
2. 单独下载后放进安装包同目录再运行安装器；
3. 已装主程序时，把组件放到安装目录后运行 `sunshine-integration.ps1 -Action install`（产品后续会做页面一键下载）。

必读说明（GPL-3.0）：
- Sunshine 与本产品是**相互独立的两个程序**，本产品只调用它的安装器与官方 REST API；
- 我们不修改 Sunshine 源码；若将来修改，会按 GPL-3.0 提供修改后的源码；
- 完整许可证文本随包放在 `docs/LICENSE-Sunshine-GPL-3.0.txt`，中文说明 `docs/高性能模式-GPL说明.txt`；
- Ubuntu/其他系统的用户可自行到上游下载对应版本。

| 位置 | 主包 | Sunshine 组件 | 说明 |
|---|---|---|---|
| Gitee Releases | ✅（需确认单附件上限） | ✅ | 主渠道；页面上放本说明+许可证 |

上传时**每个文件旁边都要带**：
1. 本文档（或等价的「说明情况」），写清是什么、为什么单独、许可证；

3. 主包的 `docs/FFmpeg-GPL说明.txt`（ffmpeg 也是独立 GPL 程序）。
