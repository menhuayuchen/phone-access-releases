# Moonlight 高性能模式 · 真机验收清单（2026-11-03）

> 用途：在一台**真实电脑 + 真实手机**上，验收「高性能模式」（Sunshine + Moonlight）是否能替代/互补网页模式。
> 验证包：`dist\真机验证-高性能模式\`（双击 `1-启动验证.cmd` 启动，`2-停止并清理.cmd` 停止）。
> 本清单是 S4 的验收表；测完把数字填上，作为是否发布的依据。

---

## 一、准备

- [ ] 电脑：Windows 10/11，显卡支持硬件编码（AMD AMF / Intel QSV / NVIDIA NVENC 任一）
- [ ] 电脑和手机在**同一个 Tailscale 账号**下、手机 Tailscale 已连接
- [ ] 手机装好 **Moonlight**（安卓：GitHub `moonlight-stream/moonlight-android` releases；
      iPhone：App Store 搜 Moonlight——中国区可能搜不到，搜不到就先用安卓机验收）
- [ ] 双击 `1-启动验证.cmd`，管理员授权点「是」，等它打印 8661 验证地址
- [ ] 手机打开同一个 8661 地址（带 `?k=`），能进页面

## 二、配对

- [ ] 手机页 → ⚙ 设置 →「高性能模式（Moonlight）」卡片显示 **已就绪**
- [ ] 手机 Moonlight 里「+」添加电脑（自动扫到 `手机远程-高性能`，或手输电脑 tailnet 地址）
- [ ] Moonlight 显示 4 位 PIN → 验证页「选这个」→ 输入 PIN → **完成配对**
- [ ] Moonlight 里能看到并进入 **Desktop**

## 四、许可证 gate

- [ ] 未授权（或临时移除 licence.json）时，卡片显示「未授权」，配对接口被拒
- [ ] 试用期内（7 天试用）可以正常配对（与"试用=全功能"口径一致）

## 五、稳定性与重启

- [ ] 连续串流 10 分钟无累积延迟（画面不越来越慢）
- [ ] 重启电脑后：Sunshine 服务自动启动、验证页状态仍「已就绪」
- [ ] 拔网/切 Wi-Fi 后恢复：Moonlight 能重连；验证页不崩

## 六、清理与卸载

- [ ] `2-停止并清理.cmd`：8661 服务停止、`PA-Verify-8661` 防火墙规则删除
- [ ] `2-停止并清理.cmd -UninstallSunshine`：服务消失、`%ProgramFiles%\Sunshine\config` 残留被删、凭据文件被删
- [ ] 正式产品（原来那个 8660 地址）不受影响

## 七、判定

- **PASS**：第三节全部达标、第四节 gate 生效、第六节清理干净。
- **PARTIAL**：只有 1080p60 达标 / 延迟偏高 / iPhone 不可用——按「网页模式为主、高性能模式为进阶」发布。
- **FAIL**：硬编不可用或延迟 >100ms——先解决驱动/编码器问题，再考虑是否发布。

## 八、已知限制（验收时确认并接受）

- iPhone 需要 Moonlight iOS 客户端（中国区可得性待确认；不行就 iPhone 用网页模式）。
- Sunshine 是 GPL-3.0 独立程序，分发需附许可证文本与上游源码链接（发布前合规确认）。
- 高性能模式只对已授权/试用中开放（否则会绕过 ¥68 买断）。
- 桌面办公的触控体验（长按右键、双指滚动、捏合缩放）网页模式更好；Moonlight 偏鼠标+键盘。

## 九、首轮真机结果（2026-11-03 20:56，部分）

手机 Moonlight 串流成功，H.264 硬解（c2.mtk.avc.decoder），截图时桌面是静态壁纸：

| 项 | 实测 |
|---|---|
| 分辨率 | 1920×1080 |
| 网络接收帧数 | 31.8 / 38.1 FPS（两张截图） |
| 渲染帧数 | 29.3 / 34.1 FPS |
| 网络丢失 | 0.00% |
| 平均网络延迟 | 23 ms（抖动 17 ms）/ 39 ms（抖动 30 ms） |
| 主机处理延迟（min/max/avg） | 1.6 / 2.4 / 1.9 ms |
| 平均解码时间 | 0.00 / 0.16 ms（硬解） |

**解读**：延迟 23–39ms、0 丢包、主机编码 1.9ms —— 这条链路已经达到预期。
帧率 32–38 不是上限：截图时桌面是**静止壁纸**，Sunshine 在画面不动时会主动降帧省带宽
（minimum_fps_target 机制），拖动窗口/播放视频时才会跑到 60。

**待补验**：动态画面下的 60fps、1440p60、声音、键盘/鼠标、锁屏恢复、卸载清理、许可证 gate。

## 十、首轮踩坑与修法（都已修进脚本）

| 现象 | 根因 | 修法 |
|---|---|---|
| 页面「已安装未运行」 | Sunshine 绑 tailnet IP 后不监听回环，代理写死 127.0.0.1 | 代理读 sunshine.conf 的 ind_address |
| 本地代理 403（Web UI denied） | origin_web_ui_allowed = pc 拒绝 tailnet 来源 | 改 lan（仍只绑 tailnet + 随机强密码 + 防火墙限 tailnet） |
| 中文名变 ????-??? | conf 用 ASCII 写 | 改 UTF-8 无 BOM |
| 第一次串流 30 秒断开、重连证书校验失败 | 协商到 AV1/HEVC，手机端解码/兼容问题 + 重复配对 | hevc_mode = 1 / v1_mode = 1 只广播 H.264；清空重复配对后重配 |
| conf 被清成一行 | Sunshine POST /api/config 是整文件覆盖 | 记录：必须一次发全量配置，或直接写 conf 文件 |
