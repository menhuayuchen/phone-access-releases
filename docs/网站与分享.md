# 网站与分享 · 落地页怎么搭（2026-10-30）

> 目的：给产品做一个能发给朋友的**落地页 + 下载入口**，并把手机端「分享给朋友」接到这个页面上。
> 结论先说：**不需要买服务器**，静态单页就够；先用 GitHub Pages 免费跑起来，国内访问慢了再换国内对象存储。

## 1. 现在有什么

| 东西 | 位置 | 说明 |
|---|---|---|
| 安装包 / Release | https://github.com/menhuayuchen/phone-access-releases/releases | 已有，下载页可以直接用 |
| 落地页草稿 | `site/index.html` | 单文件、无外部依赖、深色主题，和手机端风格一致 |

## 2. 推荐方案：静态单页（按优先级）

### 方案 A：GitHub Pages（免费，5 分钟，先跑起来）

1. 新建仓库 `phone-access-site`（Public）。
2. 把 `site/index.html` 上传成仓库根目录的 `index.html`（也可以顺手放个 `favicon.ico`）。
3. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，Save。
4. 等 1~2 分钟，网址是：`https://menhuayuchen.github.io/phone-access-site/`
5. 把这个网址填进 `product.config.json` 的 `share.link`，重启手机远程服务，分享文案里就是官网链接了。

优点：0 成本、HTTPS 自带、和 release 同一个账号。
缺点：国内部分地区/校园网访问 GitHub Pages 可能慢或打不开（下载安装包更明显）。

### 方案 B：国内对象存储静态托管（给国内客户，推荐正式上线用）

- 阿里云 OSS / 腾讯云 COS：开「静态网站托管」，上传 `index.html`。
- 绑定自己的域名 + 免费 HTTPS 证书。
- 费用：存储几分钱/月；流量约 ¥0.2~0.5/GB。安装包 50MB，一次下载约 ¥0.01~0.03。
- 注意：绑自定义域名在国内需要**域名备案**；不想备案可以先用厂商给的默认域名（能访问，但不好看）。

### 方案 C：Cloudflare Pages（免费、全球 CDN）

- 上传/连 GitHub 仓库即可，免费额度足够；国内可用但速度一般。
- 适合不想备案、又想要 HTTPS 自定义域名的过渡方案。

**建议路线**：先用 A 跑通分享链路 → 有真实用户后换 B（国内访问稳定）→ 安装包也放 B 或加国内镜像。

## 3. 下载文件放哪

| 做法 | 成本 | 备注 |
|---|---|---|
| GitHub Releases（现在） | 免费 | 国内慢；但全世界都能下 |
| OSS/COS + 页面直链 | 流量费 | 国内快；记得开 HTTPS、防盗链 |
| 蓝奏云 / 夸克网盘 | 免费 | 链接会失效、有广告页，只适合临时备用 |

不管放哪：页面上给出的下载链接要能拿到最新版；并在页面/Release 里写 **SHA256**，防止被中间替换。

> 现在 `site/index.html` 的两个下载按钮都指向
> `https://github.com/menhuayuchen/phone-access-releases/releases/latest`，
> 换成国内镜像时改这两处 `href` 即可（搜索 `releases/latest`）。

---

## 4. 上线后要改的两处

1. `product.config.json` → `share.link` 改成站点地址（例如 `https://your-domain.com/`）；
   `share.text` 里写 `{link}` 会自动替换成这个地址。
   **改完不用重新打包**，重启手机远程服务即生效（桌面「重启」）。
2. `site/index.html` 里的价格如果调了，同步改 `product.config.json` 的 `plans`
   （两处目前是手动同步；以后要省事可以让页面直接读一个 JSON）。

## 5. 落地页写什么（已按这个结构做好）

1. 一句话卖点（手机看电脑 + 能点能打字）
2. 4 个功能点（超清 / 流畅省流量 / 触控键盘 / 只在你的设备之间）
3. 三步用起来（电脑装好 → 手机扫码 → 添加到主屏幕）
4. 价格（免费 / 专业 ¥98 / 定制面议）
5. 常见问题（要不要公网 IP / 免费版会不会过期 / 流量 / 安全 / 公司电脑）
6. 下载 + 邮箱
7. 免责声明小字

改文案直接改 `site/index.html`（纯 HTML+CSS，没有构建步骤）。

## 6. 合规与隐私（重要）

- **不要在公网页面写手机号**。现在页面只放邮箱 `ccc475235@gmail.com`；要加微信就放二维码图片，
  不要放手机号（容易被骚扰/被爬）。
- **收款码不要放公网页面**，只放在软件内的「支持/购买」面板（那里有许可证绑定，风险低）。
- 免责声明保留：仅用于自己的电脑；公司电脑不要装。
- 产品名里不要出现「破解 / 免安装 / 绿色版」之类容易被平台误判的词。
