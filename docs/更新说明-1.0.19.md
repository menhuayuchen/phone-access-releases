# 轻屏 1.0.19 更新说明（草案，待虚拟机复验后发布）

> 触发：用户在 Windows 虚拟机里实测 1.0.18，报了三件事：
> ① 安装包里的 Sunshine（高性能组件）会卡住安装；② 安卓虚拟机里清晰模式不可用；
> ③ 「调分辨率」那一栏是空的。

## 面向使用者的变化

**安装器（重点）**
- 高性能组件（Moonlight / Sunshine）改为**可选、默认不安装**：第 11 步会问一次
  「现在安装吗？[Y=装 / N=跳过，15 秒后自动跳过]」；不选就跳过，网页模式完全不受影响。
  - 旧版默认安装：机器上已经装过 Sunshine 时会等安装锁，可能把整个安装器卡住。
- **没有网络时自动跳过**高性能组件（不再尝试安装）。
- 这一步总超时 5 分钟；超时会连同它拉起的 `msiexec` 一起结束，继续后面的步骤，不会卡死。
- 无人值守安装（`-NoPause`）默认跳过；要显式安装可加 `-HighPerformance`。

**清晰模式（虚拟机 / 远程桌面 / 锁屏）**
- 服务端按**真实运行结果**判断清晰模式是否可用：
  编码器连续两次秒退 → 标记"暂不可用"（60 秒后自动重试）；出第一帧 → 恢复"可用"。
  - 不再用"启动探测"一锤定音：锁屏/刚开机时 ddagrab 会短暂失败，一探就禁用会误伤正常机器。
- 页面行为：
  - 加载时先问一次可用性；已知不可用 → 直接进**流畅**并提示原因，不再先黑屏 8 秒；
  - 清晰模式失败时自动切回流畅并提示（"清晰模式暂时不可用：…（约 N 秒后自动重试）"）；
  - 修复"清晰→低频→再清晰"来回跳：图片错误重试不再无视当前模式强行拉回 mjpeg。
- 设置 → 画质与流量 里显示「清晰模式：可用（编码器 nvenc/mf）」或
  「暂时不可用 —— 原因（约 N 秒后自动重试）」。

**设置面板**
- 修复「分辨率」下拉偶发空白：服务端采集宽度不在选项里时（虚拟机常见），
  自动选最接近的档位并提示实际采集宽度。

## 已知取舍

- 清晰模式依赖桌面复制采集（Desktop Duplication）；虚拟机、部分远程桌面、无 WDDM 抓屏的
  环境不可用，这是 Windows 的限制，不是安装问题。流畅模式（MJPEG / WebRTC）在这些环境照常可用。
