> 这份文档是**操作手册**：从接到一个客户，到客户每天正常使用，两边各要做什么。
>
> 两条线分开看：
> - **【卖家】S1–S7** —— 你要做的
> - **【客户】C1–C7** —— 客户要做的（客户只看 C 部分就行，那份在 `使用说明.md` 里）

### 1.1 确认这三样东西在

| 东西 | 位置 | 作用 |
|---|---|---|


**验收**：构建结束会打印"文件数一致: True"和"自验证通过"。

## S3 · 交付安装

### 3.1 你发什么

**只发一个文件**：

```
【点这里安装】手机远程-v1.0.3.exe   （约 50 MB）
```

微信可以直接发（小于 100 MB）。

### 3.2 客户会遇到的第一道坎：智能屏警告

**未签名程序必弹**"Windows 已保护你的电脑"。

你要提前说清楚，否则客户会以为中毒：

> 双击之后屏幕可能变蓝、写着"Windows 已保护你的电脑"。
> **这不是病毒**，是因为我没买数字证书（一年几千块）。
> 点「**更多信息**」→「**仍要运行**」就行。

### 3.3 安装过程（客户做，你远程看着）

安装器会自己跑 10 步左右，中间会：

| 步骤 | 客户要做什么 |
|---|---|
| 提权 | 点「是」（整个安装只弹这一次） |
| 环境检查 | 不用管，失败会停并说明原因 |
| Tailscale | **如果用客户的账号登录**：客户要注册/登录 Tailscale |
| 复制文件 | 等 1–3 分钟，不要关窗口 |
| 建桌面文件夹 | 自动，桌面出现「手机远程」 |
| 开机自启 | 自动注册计划任务 |

**如果卡住了**：让客户把 `桌面\手机远程\报告\` 里的失败报告发给你。

## S4 · 签许可证（核心环节）

### 4.1 先拿到客户的机器码

机器码形如 `A1B2-C3D4-E5F6-7890`，客户从**两个地方**都能看到：

| 方式 | 客户怎么做 |
|---|---|
| **手机上看**（推荐） | 手机上打开入口地址 → 点右下角 **❤（支持 / 购买）** → 面板里显示机器码，可一键复制（半免费后没有整屏遮罩了，机器码在 ❤ 面板和 设置→许可证 里） |
| 电脑上看 | 双击桌面 `手机远程\手机入口`，或打开 `报告\` 里的自检报告 |

### 4.2 你签发

```
双击 seller-keys\签发许可证.cmd
  → 输入机器码
  → 输入客户名（会显示在手机上，写客户能认出来的名字）
  → 有效期（留空 = 永久）
  → 它会打印一段"可直接发给客户的话"
```

### 4.3 发什么给客户

工具会生成一段**短码**（base64 文本）。直接微信发那段话即可。

**别发整个 licence.json 文件**——客户还得找目录改名，容易出错。短码粘一下就行。

### 4.4 体验版（¥10 / 1 个月）怎么签

体验版不是新机制，就是一张 **30 天有效期的正式许可证**，签发时多两个参数：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File seller-keys\make-licence.ps1 `
  -Machine "客户机器码" -Name "客户名" -Days 30 -Edition trial
```

- `-Days 30`：从今天起 30 天（也可以用 `-Expires 2026-12-01` 指定日期，两个只能给一个）。
- `-Edition trial`：手机上显示**蓝色「体验版」**徽章 + 剩余天数；不写这个参数会显示"专业版"（功能一样，只是标签不同）。
- 签完把 `licence-….code.txt` 的内容（一行短码）发给客户，粘到 **设置 → 许可证** 即可。
- **每台电脑最多卖 3 次体验版**：卖之前跑一次
  `powershell -NoProfile -ExecutionPolicy Bypass -File tools\count-trial-licences.ps1 -Machine "客户机器码"`
  看已买几次。统计依据是本机 `seller-keys\licence-*.json`，**这些文件就是你的销售台账，别删**。
- 续期 = 再签一张 30 天的（会覆盖旧许可证；天数从签发当天算，不是从旧到期日累加）。
- 为什么不能自动限制次数：产品是离线授权（没有中心服务器），客户端记不住"买过几次"；
  删文件/重装都能绕过。所以次数靠你人工核对，别承诺"系统自动限制"。

## S5 · 交付验收（不做这一步别收钱）

让客户**当场**做完这四件事，你看着：

| # | 验收项 | 通过标准 |
|---|---|---|

## S6 · 售后

### 6.1 客户常见问题（按频率排）

| 客户说 | 真正原因 | 你怎么处理 |
|---|---|---|
| "手机连不上了" | 电脑关机/睡眠，或 Tailscale 断线 | 让客户看电脑右下角 Tailscale 图标是不是绿的 |
| "画面很卡" | 用手机流量看清晰模式（26 GB/小时） | 让客户点「**流畅**」，并把《使用说明》第四节的流量表发他 |
| "点不动" | 客户没开「控制」按钮，或者前台是高权限窗口 | 让客户点「控制」；后者等他自己点一下屏幕 |
| "打不开了" | 服务没起来 | 双击桌面「**重启**」 |
| "电脑重启后连不上" | 开机自启没生效 | 让他双击「启动」；还不行跑「自查」把报告给你 |
| "手机换 WiFi 后连不上" | 换了网段 | 用域名那条地址（`https://xxx.ts.net/?k=...`），不要用局域网 IP |

### 6.2 版本更新

**客户不会自动更新。** 刷新页面只拿到**已经在他机器上**的版本。

要更新客户：**让他重跑一次安装包**（配置和许可证都会保留，我验证过）。

### 6.3 退订 / 不再使用

让客户双击桌面 `手机远程\卸载`：

- 会二次确认（要输入 YES）
- **默认保留许可证**（以后重装同一台电脑不用重新申请）
- 六步撤干净：停进程 → 删计划任务 → 删防火墙规则 → 撤销 Defender 排除 → 删桌面文件夹 → 删安装目录

# 第二部分 · 客户侧（客户只看这部分）

> 以下内容与 `使用说明.md` 一致，可以直接转发给客户。

## C1 · 装之前

你要准备：

1. **一台 Windows 10/11 电脑**（不能是公司统一管理的）
2. **一个手机**（安卓或 iPhone 都行）
3. **大约 10 GB 空闲硬盘**

## C2 · 安装（双击，跟着走）

1. 双击 `【点这里安装】手机远程.exe`
2. 如果弹出蓝色"已保护你的电脑" → 点「**更多信息**」→「**仍要运行**」
3. 点「**是**」允许管理员权限（整个安装只弹这一次）
4. 按提示装 **Tailscale**，用**你自己的账号**注册登录
5. 等 1–3 分钟，不要关窗口
6. 桌面上会出现「**手机远程**」文件夹

**装完桌面文件夹里有 6 个图标**：
`启动` · `重启` · `自查` · `停止` · `手机入口` · `卸载`
还有一份 `使用说明.md`。

## C3 · 激活许可证

**不激活也能直接用**（免费模式：超清每天 1 小时、个性化锁定，其余全免费）。要激活：

1. 手机上打开卖家给你的网址 → 点右下角 **❤** → 复制**机器码**发给卖家
2. 想付费解锁时：❤ 面板里有微信/支付宝收款码，付款截图 + 机器码一起发卖家
3. 卖家回你一段文字 → 打开**设置（⚙）→「许可证」分区** → 粘进「粘贴到这里激活」输入框 → 点「验证并安装」
4. 约 10 秒生效，页面自动刷新（也可以把 `licence.json` 文件放进 `%LOCALAPPDATA%\PhoneAccess`，10 秒自动生效）

## C4 · 装到手机桌面（像 App 一样用）

**安卓（Chrome / Edge）**：

1. 用浏览器打开入口地址
2. 右上角菜单 → 「**添加到主屏幕**」/「安装应用」
3. 图标出现在桌面

**iPhone（Safari）**：

1. 用 **Safari** 打开（不要用微信内置浏览器）
2. 底部「分享」按钮 → 「**添加到主屏幕**」

> **第一次用必须打开一次页面**，之后从桌面图标直接进。

## C5 · 每天怎么用

### 三个画质按钮，看场合选

| 按钮 | 每小时流量 | 什么时候用 |
|---|---|---|
| **清晰** | 约 26 GB | **只在手机连同一个 WiFi 时用** |
| **流畅** | 约 1.3 GB | **用手机流量时点这个** |
| **省流量** | 约 1.1 GB | 只想瞄一眼进度 |

> ⚠️ **30 GB 的流量套餐，用「清晰」看一小时就没了。**
> 出门在外一定点「流畅」。

### 设置（⚙）里还有画质三档

| 档位 | 宽度 | 说明 |
|---|---|---|
| **超清** | 2560 | 免费每天 1 小时；许可证不限时长。用完自动按高清出图，明天 0 点恢复 |
| **高清** | 1920 | 免费不限时 |
| **标准** | 1440 | 免费不限时，最省流量 |

改档位后要双击桌面「手机远程」里的**「重启」**才生效。设置里还有**个性化**（主题/光标，许可证功能）。

### 触摸怎么操作

| 手势 | 效果 |
|---|---|
| 点一下 | 左键单击 |
| 按住拖 | 拖拽（拖窗口、拖文件） |
| 双击 | 双击 |
| 长按 | 右键 |
| 双指滑 | 滚轮 |
| 双指捏合 | 缩放看细节 |

### 「控制」按钮是总开关

关掉后只能看，点不动。**只想看不想碰时先关掉它。**

## C6 · 出问题按这个顺序查

| 症状 | 先做什么 |
|---|---|
| 手机打不开 | 1. 电脑是不是开着 / 没睡眠<br>2. 电脑右下角 Tailscale 图标是不是绿的<br>3. 双击桌面「重启」 |
| 能看但点不动 | 点一下「控制」按钮看是不是关着 |
| 画面卡 | 点「流畅」 |
| 电脑重启后连不上 | 双击桌面「启动」 |
| 还是不行 | 双击桌面「自查」，把 `报告\` 里的文件发卖家 |

## C7 · 卸载

双击桌面 `手机远程\卸载` → 输入 `YES` 确认。

- 默认**保留许可证**（重装同一台电脑不用重新申请）
- 会删掉：程序文件、开机自启、防火墙规则、桌面文件夹
- 不会动：Tailscale（你还想用就留着）

# 第三部分 · 故障对照表（你自己排查用）

| 现象 | 可能原因 | 你怎么查 |
|---|---|---|
| 手机 502 | 服务在重启窗口期 | 等 10 秒重试 |
| 手机提示「超清已用完」 | 免费模式每日 1 小时配额到了 | 正常现象：自动按高清出图，明天 0 点恢复；`/health` 里 `uq=0:x` 可确认 |
| 手机白屏 | 服务起来了但抓屏没出帧 | 看 `/health` 的 `in=` 是不是 0 |
| 画面有但很卡 | 抓屏 CPU 吃满 | 看 `in=` 与 `cap=`；降分辨率或关掉占 CPU 的程序 |
| 「重启」失败说端口被占 | 自己的进程没被认出来 | 已经修过；如果复发，把报告发我 |
| 装到第 4 步失败 | 复制文件内容校验不过 | 让客户重启电脑再装；还不行要报告 |
| DSH 网址没了 | `enableDsh=false` | 改配置 → 双击「重启」 |

**日志位置**（出问题让客户发这些）：

```
%LOCALAPPDATA%\PhoneAccess\screen-server.log     画面服务
%LOCALAPPDATA%\PhoneAccess\screen-capture.log    抓屏
%LOCALAPPDATA%\PhoneAccess\web-lan.log           DSH
桌面\手机远程\报告\                              自检报告 + 安装失败报告
```

# 第五部分 · 边界与承诺（对客户说的话）

你可以在谈单时直接说这四条：

1. **我没有你电脑的访问权。** 不是"我保证不看"，是**技术上进不去**——你用的是你自己的 Tailscale 账号，我不是那个网络的成员。
2. **需要我帮忙时，由你开临时窗口**，系统自动关，不靠你记得关。
3. **产品不联网。** 源码里除了 `127.0.0.1` 没有任何外部地址，没有遥测、不回连。
4. **许可证在哪台机器就在哪台机器**，换电脑要重新申请。
