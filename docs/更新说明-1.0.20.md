# 轻屏 v1.0.20 更新说明

> 发布日期：2026-11-09
> 安装包：`LightScreen-Setup-v1.0.20-release.exe`（92.3 MB）

## 这次改了什么

### 画面更顺，不再"抽搐"

**整屏抓屏换成 DXGI**（Windows 桌面复制 API）：

- 之前抓一帧要 32 毫秒，现在不到 1 毫秒
- 画面快速变化时不再出现那种"一卡一卡"的抽搐感
- 顺带把占用的 CPU 让给了编码器，整体更流畅

### 声音不会再"莫名没声"

加了一个**音频看门狗**：声音服务如果卡死（进程还在但不出声），守护会自动把它重启，不用你手动操作。

### 帧率显示不再吓人

以前画面静止时，帧率会显示成「… fps」，看着像出故障。现在：

- 画面静止 → 显示「**静止**」（这是正常的，不是坏了）
- 正常有画面 → 显示实际帧率

### 修了一个"画面明明没卡却被强制重连"的问题

之前如果 2.5 秒内没收到新画面数据，程序会误判"连接断了"然后强制重连——你看到的就是画面卡一下、帧率变成「…」。

现在会先问服务端"你还活着吗"，活着就只是画面静止，不会乱重连。

### 安装体验改善

- **安装进度可见**：解压时会显示百分比（`准备中 0%…100%`、`解压中 0%…100%`），不会长时间黑屏让你以为卡死
- **窗口更少**：启动器直接以管理员身份运行，安装过程少了 cmd 黑窗口，也不会再弹第二次管理员授权
- **装完只弹一个页面**：以前装完会同时弹出图片查看器（二维码）+ 记事本（网址）+ 资源管理器，现在合并成一个「手机入口」页面，二维码、网址、机器码、接下来要做的三步都在里面
- **中文不再乱码**：修了安装过程中文显示成 `瑙ｅ帇涓?` 这种乱码的问题

### 其他修复

- **电源计划**：支持「周末」重复规则；每条规则可以单独开关；时间输入兼容 `23:00` 和 `11:00 PM` 两种写法
- **缩放浮条**：位置和大小修正，不再挡住底部按钮

## 升级方式

**直接装新的安装包就行**，会覆盖旧版本，不需要先卸载：

- **许可证会保留**（不需要重新授权）
- **画质设置会保留**
- 安装目录：`%LOCALAPPDATA%\PhoneAccess`

## 已知事项

- 安装包体积 92.3 MB（含运行环境，不需要另外装 Node.js）
- 首次安装需要管理员权限（会弹一次 UAC，点「是」）
- 装完建议重启一次电脑再连，确认"重启后还能连"才算真的装好

## 出问题怎么办

双击桌面「轻屏」文件夹里的「**自查**」，它会生成一份报告，把这个报告文件发给卖家即可。
