# 手机远程 · 宣传要点与改进路线（2026-11-03）

> 当前公开版：v1.0.14（更新源已改 Gitee 优先，设置里有「安装备选」）。
> 本文只做宣传口径与改进清单，不代表已经实现。

---

## 一、一句话卖点

**手机不用装远控 App，浏览器打开就能看电脑、点鼠标、打字、听声音；画面走 Tailscale 加密网络，不经过远控厂商的中转服务器；免费版够日常用，专业版 ¥68 一次买断。**

## 二、三条核心优势（对外可直接用）

### 1. 隐私路径不一样：没有远控厂商中继，也不用注册厂商账号

- 画面/输入走 Tailscale（WireGuard）加密网络，不经过我们或远控厂商的中转服务器；
- 不需要注册我们的账号，不把设备列表/画面交给第三方远控平台；
- 访问靠本机生成的密钥 + cookie；许可证离线校验、按机器绑定；
- 对隐私敏感、已有 Tailscale 的用户，这是最硬的差异。

> 诚实补充：需要注册/登录 Tailscale（免费），Tailscale 自己可能有 DERP 中继；我们说的是“不经过远控厂商的中转”。

### 2. 价格：买断制，长期用明显便宜

- 免费版：高清 1920 与标准画质不限时，超清 2560 每天 1 小时，最多 3 台同时看；
- 体验版：¥10 / 1 个月全功能；
- 专业版：**¥68 一次买断**（含 1 年更新；之后不续也能继续用当前版本）；
- 对比：ToDesk / 向日葵专业档约 ¥158/年；AnyDesk Solo 约 ¥123/月（按年付）。

### 3. 轻：手机不用装远控 App，浏览器/PWA 直接用

- iPhone / iPad / Android 都是浏览器打开，不用装远控 App、不用应用商店；
- 电脑端一个安装包（Windows 10/11），不需要公网 IP、不需要路由器端口映射；
- 没有广告、没有会员弹窗、没有“免费版限时”。

## 三、适合谁 / 不适合谁（宣传时别夸大）

**适合：**
- 已经在用 Tailscale 的开发者、远程办公、极客用户；
- 隐私敏感、不想把画面交给第三方远控平台的人；
- 长期用、不想每年订阅的人；
- 只需要“手机看电脑 + 点鼠标 + 打字 + 听声音”的轻办公。

**不适合：**
- 完全不想折腾网络的小白（要装 Tailscale）；
- 企业 IT 支持/需要统一管理、审计、SSO 的团队；
- 需要文件传输、剪贴板、多屏控多屏、远程开机、登录界面远控的人；
- 游戏/高帧/4K HDR/安卓被控等重度场景。

## 四、改进清单：先列出来，不现在改

### A. 现在就能做（低成本、风险低，1~5 天）

| 改进 | 价值 | 说明 |
|---|---|---|
| Tailscale 一键体检/引导 | ★★★★★ | 检测是否安装、是否登录、是否在线；缺安装包就直接拉起；把最大门槛降下来 |
| 声音自动跟随默认设备 | ★★★★ | audio.exe 监听默认设备变化，换耳机/扬声器不再要重启 |
| 连接诊断面板 | ★★★★ | 显示直连/中继、延迟、分辨率、帧率、实际带宽，用户能自己判断“卡在哪” |
| 分享素材/落地页对比 | ★★★★ | 把“无中继、买断、免装 App”做成对比表/首屏；已有分享文案可继续迭代 |
| 小文件传输 / 文本剪贴板 | ★★★★ | 最常被问的功能；先做文本+小文件，注意鉴权/大小限制 |
| 安装包代码签名 | ★★★★ | 减少 SmartScreen 拦截、提升信任；需要证书（有成本） |
| 隐私说明/安全白皮书 | ★★★ | 写清数据路径、密钥、许可证、Tailscale 依赖，增强转化 |

### B. 需要一定开发（1~4 周，能做但别顺手做）

| 改进 | 价值 | 难度/说明 |
|---|---|---|
| 60fps / H.264 硬编 | ★★★★★ | 目前约 30fps、MJPEG/WebRTC；要改采集/编码/传输，工作量大但能明显改善“卡”的感知 |
| 多显示器/多窗口更好用 | ★★★★ | 已有来源选择；要做“多屏同时看/切换更快”需要 UI+协议扩展 |
| 无人值守/登录界面远控 | ★★★ | 现在锁屏可以，登录界面不行；要服务化/会话 0，安全风险高，建议先做自动登录引导 |
| 远程开机/WOL | ★★★ | 需要网卡/路由器支持，场景有限；可做“局域网 WOL + 说明” |
| 移动端 PWA 打磨 | ★★★ | 全屏、后台恢复、音频自动播放、手势提示；成本中等 |
| 录像/会话审计 | ★★ | 企业向；个人用户价值低 |

### C. 不建议现在做（成本远超收益）

- **原生 iOS/Android App**：PWA 已够用，双端开发和商店审核成本高；
- **Mac/Linux 被控**：要重写采集/输入/权限，几个月起步；
- **安卓/iOS 被控**：完全不同技术栈，且涉及合规；
- **游戏级 144fps / 4K HDR / 手柄**：打不过 Parsec/ToDesk 游戏版，不是我们的用户；
- **企业 SSO/审计/集中管理/私有化**：一人团队打不过 ToDesk/向日葵的销售与合规；
- **自建全球中继网络**：成本极高，且违背“无厂商中继”的定位。

## 五、建议的定位

不要做“ToDesk 平替”，做 **“Tailscale 用户的买断制隐私远控”**：

- 关键词：**不经过远控厂商、¥68 买断、手机免装 App、无广告**；
- 渠道：Tailscale 中文社区、开发者群、B 站教程、Gitee；
- 先把“装 Tailscale”这一步做顺，比加十个功能更能提升转化。
