# 隐私与安全说明（白皮书）

> 适用：手机远程（Windows 电脑被控、手机浏览器控制）
> 更新：2026-11-03 · 对应版本：1.0.14 之后的下一个版本（含剪贴板/文件传输）
> 用途：对外解释「数据怎么走、谁能连、我们能不能看到」；也是给客户看的信任材料。

---

## 一、一句话

**画面和操作只在你自己的手机和电脑之间，通过你自己的 Tailscale 网络（WireGuard 加密）传输；
我们（卖家）没有中转服务器、没有你的设备账号、也没有任何远程入口——技术上进不去你的电脑。**

---

## 二、数据路径

```
手机浏览器（PWA）
   │  你的 Tailscale 账号（WireGuard 加密，设备间点对点；必要时经 Tailscale 自己的 DERP 中继，仍是端到端加密）
   ▼
你的电脑：screen-server（只监听 127.0.0.1 和你的 tailnet 地址 100.64.0.0/10）
   ├─ 画面：capture.exe 抓屏 → MJPEG / WebRTC（只在你的网络里）
   ├─ 声音：audio.exe 采集 → 命名管道（进程间，不落盘）
   ├─ 输入：input.exe 注入（只接受通过鉴权的请求）
   └─ 剪贴板/小文件（新版本）：同一鉴权，落盘只在 下载\PhoneAccess\
```

- **不经过我们**：产品没有任何「厂商中转服务器」；我们也没有你 tailnet 的访问权。
- **不注册我们的账号**：只需要你自己的 Tailscale 账号（免费）。
- **不开放公网端口**：不监听 0.0.0.0，不做端口映射；只监听本机和你的 tailnet 地址。
- **局域网直连也被拒绝**：即使手机和电脑在同一个 Wi-Fi，服务端也只接受回环或 100.64.0.0/10 来源。

> 诚实补充：Tailscale 自己是一个第三方服务（免费额度足够个人用），它负责设备发现和加密网络。
> 如果两台设备无法直连，Tailscale 会用自己的 DERP 中继转发——中继看到的是加密流量。
> 我们说的是「不经过远控厂商的中转」，不是「不需要任何第三方基础设施」。

## 三、谁能连上

| 门槛 | 说明 |
|---|---|
| Tailscale 登录 | 手机和电脑必须登录**同一个** Tailscale 账号 |
| 访问密钥 | 电脑第一次启动时生成一串随机密钥（`screen.key`，32 位），地址里带它；换设备要重新扫 |
| Cookie | 浏览器第一次带密钥打开后种 cookie；PWA 首次打开用带密钥的地址 |
| 来源闸门 | 只接受 127.0.0.1 / ::1 / tailnet `100.64.0.0/10`，其余 403 |
| 公开白名单 | 只有 `/health`（计数）、`/sw.js`、图标、收款码图片是公开的；**画面、输入、许可证、清单都必须带密钥** |

2026-11-01 的 v1.0.12 修过一次鉴权问题：当时 `tailscale serve` 把请求变成 127.0.0.1，
旧的「本机自连免鉴权」让同一 tailnet 的设备可能不带密钥读到 `/frame.jpg`、`/stream`、`/licence`。
现在模型改成「默认必须密钥 + 显式公开白名单」，并把 `/rtc`、`/ws-audio` 也加了来源闸门。

> 密钥就是钥匙：**别把带 `?k=` 的地址截图发人、别贴群里**。怀疑泄露就在电脑上重新生成（重启一次会换）。

## 四、许可证与机器码

- 许可证是 **RSA-2048 签名的 JSON**，内含你的名字（可自定义）、机器码、签发日期、有效期、版本。
- 校验**完全离线**：产品里只有公钥，校验时不需要联网、不上报设备信息。
- 机器码 = `SHA256(CPU ProcessorId | 主板序列号 | 主板型号 | SMBIOS UUID)` 取前 16 位 → 形如 `01D1-8E7B-FD02-076B`。
  - 它是**单向哈希**，不能反推出你的硬件明细；
  - 换硬盘、重装系统**不影响**许可证；换 CPU/主板才需要重发；
  - 2026-11-03 起加入 SMBIOS UUID：同型号的 DIY 机器不再共用同一个机器码（防止一份许可证装两台）。
- 旧的许可证（旧算法）继续有效，不用重新签发。
- 7 天试用是本地记录；如果卖家部署了「试用台账」（可选项），客户端在**本地记录被清掉时**才会把
  **机械码哈希**发到卖家的小接口一次，用来防止"重装系统反复领试用"。不采集任何个人信息。

## 五、联网行为：什么时候才会连出去

| 动作 | 联网 | 说明 |
|---|---|---|
| 正常使用画面/操作/声音 | 不联网（除 Tailscale 自身） | 只在你的网络里 |
| 点「检查更新」 | 是，一次 | 查 Gitee（主）/ GitHub（备选）；只有你点才发生 |
| 应用内下载更新 | 是 | 从 Gitee/GitHub 下载安装包，下载后**校验 SHA256** 才能运行 |
| 试用台账（可选） | 是，仅在本地试用记录被清掉时 | 只上传机械码哈希；连不上就退回本地，不影响使用 |

产品**不做**：后台心跳、遥测、崩溃上报、广告 SDK、设备画像、云端账号。

## 六、哪些数据会落盘

| 位置 | 内容 | 说明 |
|---|---|---|
| 安装目录（`%LOCALAPPDATA%\PhoneAccess`） | 程序、配置、密钥、日志 | 日志只用于排障，可随时删 |
| `%LOCALAPPDATA%\PhoneAccess\screen.key` | 访问密钥 | 重启会换 |
| `%ProgramData%\PhoneAccess` / 注册表 | 试用锚点（起始时间哈希） | 不含硬件明细 |
| `下载\PhoneAccess\`（新版本） | 手机上传的文件 | 你自己能删；只允许上传，不能远程读电脑上的其它文件 |
| 剪贴板（新版本） | 不落盘 | 写入后由系统剪贴板保存，内容不写日志 |

## 七、卖家能不能帮你看电脑？

**不能。** 产品没有"技术支持通道"、没有隐藏账号、没有反向连接、不给我们开任何端口。
你出事时能提供的只有：截图、日志、机器码——都需要你主动发。

## 八、边界与已知限制（不吹牛）

- 电脑必须开机、联网、程序在运行；锁屏可以，登录界面不行（需要 Windows 自动登录）。
- Windows 的 SmartScreen 可能提示"未知发布者"：安装包**没有购买代码签名证书**，SHA256 可在官网核对。
- 手机端是浏览器/PWA，不是原生 App；极端低配/老浏览器可能不支持 WebRTC 流畅模式。
- 强依赖 Tailscale：Tailscale 服务异常或被网络限制时，产品不可用。
- 「试用台账」是缓解措施，不是绝对防破解：客户断网 + 重装系统 + 清记录时仍可能重新领试用。

## 九、你可以自己验证

```powershell
# 1) 看监听地址：应该只有 127.0.0.1 和 100.x（tailnet），没有 0.0.0.0 / 192.168.x
netstat -ano | findstr :8660

# 2) 看服务只接受 tailnet：窗口里 /health 是公开计数，画面/输入接口不带密钥应 401
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:8660/frame.jpg      # 期望 401
curl.exe -s -o NUL -w "%{http_code}" "http://127.0.0.1:8660/frame.jpg?k=<你的密钥>"   # 期望 200

# 3) 看 Tailscale 管理台：只应有你自己的设备
```
