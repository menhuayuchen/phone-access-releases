常见问题

下载之前先看这几条。

手机怎么装 Tailscale？（国内怎么下载）

不管手机和电脑在不在同一个 Wi-Fi，手机都必须装 Tailscale，并登录和电脑同一个账号（免费版够用）。
同一 Wi-Fi 下 Tailscale 会自动走局域网直连，速度更快；但从安全上不允许绕过 Tailscale 直接连电脑。
· 安卓：Google Play 搜 Tailscale；打不开 Google Play 就用官方 APK： github.com/tailscale/tailscale-android/releases （选 tailscale-android-universal-*.apk，约 100 MB；GitHub 慢就找作者要镜像）。
· iPhone / iPad：App Store 搜 Tailscale（开发者 Tailscale Inc.）； 中国大陆区 App Store 可能搜不到，需要非大陆区 Apple ID。装不上就先用电脑在本地使用，或找作者帮忙想办法。
· 电脑端：安装包里已经带了 Tailscale 安装器，安装时会引导你装。

电脑关机或睡眠了，还能连吗？

不能。它需要电脑开机、联网、程序在运行——不会替你开机。安装时要按提示把 Windows 的「自动睡眠」关掉（设置 → 系统 → 电源 → 屏幕和睡眠都选「从不」），否则电脑睡着就会断线。

可以放大画面看小字吗？

网页本身没有做双指缩放（双指手势用来滚动页面内容）。想看细节建议选「超清」档；部分手机可以用系统的放大功能（iOS 辅助功能 → 缩放 / 安卓无障碍 → 放大手势）。

下载有两个地址（Gitee / GitHub），该用哪个？

两个地址是同一份安装包（版本、大小、SHA256 都一样），只是存放的服务器不同：国内网络优先用 Gitee（快，实测 1.3 MB/s）；海外或 GitHub 能正常访问时用 GitHub（官方发布页，版本记录完整）。哪个打不开就换另一个；都不行就发邮件要网盘链接。

需要公网 IP 或者路由器端口映射吗？

不需要。手机和电脑都登录 Tailscale 后，通过 Tailscale 的私有网络直连（同一 Wi-Fi 下会自动走局域网直连，更快）；在外面也一样，不用把电脑暴露到公网。

免费版会不会用几天就不能用了？

不会。免费版永久可用：画面、触控、声音、流畅模式、高清/标准画质都不限时。限制只有两条：超清每天 1 小时、最多 3 台设备同时看。新装另有 7 天全功能试用。

手机流量看得多吗？

看模式：流畅模式实测约 1/20 的流量；清晰模式按画质档位，标准档约 8 GB/时，超清约 26 GB/时。临时看一眼建议用流畅或省流量模式。

安全吗？会不会被别人连上？

访问地址里带一把随机密钥，只有拿到完整地址的设备能打开。软件不在我们服务器中转，也不开放公网端口。但地址和二维码就是钥匙——别截图发人、别贴群里。

公司电脑能装吗？

不建议。公司统一管理的电脑通常有安全策略，装了也可能被拦；而且远程看公司电脑可能违反公司规定。用自己的电脑。
