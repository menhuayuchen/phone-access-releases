常见问题

先看这几条，多半能省一次往返。

要装 App 吗？

不用。手机浏览器打开网址就能用；想更像 App，可以在浏览器菜单里「添加到主屏幕」。

画面经过你的服务器吗？

不经过。默认走 Tailscale 的点对点加密通道（直连或 Tailscale 自己的中继），我这边没有你的画面和文件。

为什么第一次打开提示"不安全"？

局域网/自签证书会这样。点「高级 → 继续前往」即可；用 Tailscale 的 https 地址不会提示。

只支持 Windows 吗？

是。一个人做，精力有限，先把 Windows 做好；Mac/Linux 以后再说，不承诺时间。

能拿来商用吗？
